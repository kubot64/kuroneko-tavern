# 黒猫亭 ― 迷宮のほとりの酒場

Wizardry 風の迷宮に複数の冒険者パーティが潜る様子を、酒場の店主として「遠見の水晶」で眺める放置RPG。

- 単一の HTML ファイル（`index.html`）で動く。ブラウザで開くだけで遊べる
- 進行はブラウザの localStorage に保存され、閉じているあいだも時間が進む

## 舞台

ハルヴァント大陸の東、灰の荒野。約80年前に沈んだエスタリアの王都の跡に開いた全30階の迷宮と、そのほとりの街ロウエン。
若い店主が借金をして開いたばかりの黒猫亭が、三十年来の老舗・銀の杯亭を追いかける。

詳しい設定は [docs/setting.md](docs/setting.md)。

## 主な仕組み

- 冒険者：種族・職業・出身・年齢・性別・性格・口調・口癖・得意不得意・夢・二つ名・絆
- 一行：リーダーが仲間を集めて結成（基本6人）。後継ぎ・解散・仲間割れあり
- 迷宮：30階・7区画・転移の石碑・名のある魔物・黒竜・沈んだ王、記録の断片
- 鉄の山脈の坑道：迷宮を踏破すると開く二つ目のダンジョン。坑道B1〜25F・4区画・坑道王
- 店：借金の返済、席の拡張、回復薬の差し入れなどの支援、武具屋・地図屋、番付
- 持ち込まれる話：借金を返し終えると、店に話が持ち込まれる。誰を主役に回すかを、話の文面の手がかりと冒険者の個性を照らし合わせて決める。見込んだ常連を3人まで選べる

ゲームの仕組みの詳しい決まりは [docs/spec.md](docs/spec.md)。

## 仕様のテスト

`docs/spec.md` に書かれた決まりが成り立っているかを確かめる。node だけで動き、ブラウザは要らない。

```
node tools/spec-test.mjs                 # 乱数の種を48個、それぞれ30000刻（600日）回す。4コアで5分ほど
node tools/spec-test.mjs --seeds 12      # 急ぐときは種を減らす（4コアで1分ほど）。めったに起きない不具合は見逃しやすくなる
node tools/spec-test.mjs --seed 8919     # 不合格のとき、反例に出た種だけを回して再現する
node tools/spec-test.mjs --jobs 2        # 同時に回す数を絞る（ふだんは CPU のコア数）
```

- 仕様の表（席の拡張、店の設備、借金の返済など）とコードの値が一致するかを見る。
- ゲームを回しながら、毎刻成り立つはずの性質（席の数を超えない、伝説の品は世界にひとつずつ、など）を見る。
- 種ごとに別のスレッドで回す。ゲームの中身がエラーで止まった種も不合格になる。
- 不合格なら、最初の反例（種・刻・中身）を出して、終了コード1で終わる。

## 釣り合いを測る

迷宮と坑道が何日目に、どちらの店の、どのくらいのレベルの一行に踏破されるかを、乱数の種ごとに測る。**大きな変更をしたら、支援なしと支援ありの両方で測り、結果を PR に書く。**

```
node tools/measure.mjs                          # 種8個、1200日まで。支援なしと支援ありの両方
node tools/measure.mjs --seeds 16 --days 1400   # 釣り合いを決めるときはこちら（4コアで4分ほど）
node tools/measure.mjs --mode support           # 片方だけ（none か support）
node tools/measure.mjs --detail                 # 50日ごとの坑道の最深と上位のレベルも出す
```

- **支援なし**：店主は何もしない。借金は毎月の返済だけで返す。
- **支援あり**：店主が毎日1度、手元に蓄えを残しながら、帳場と武具屋の支援を使う。借金を早めに返し、席を広げ、回復薬5本・地図代・蘇生代・新人への支度の品の方針をすべて使い、常連に品を贈り、設備を建て、寺院に寄進し、親方に特注を打たせる。引き抜き・裏通りの酒場・持ち込まれる話・見込みは使わない。
- 種ごとに、借金の完済日、迷宮の踏破日と店と一行のレベル、坑道が開いた日、坑道の底に着いた日、坑道王と戦った回数、坑道の踏破日と店と坑道王と戦う前の一行のレベルを出す。
- 最後に、どちらの店が何回踏破したか、踏破日の中央値、借金完済の中央値、評判の中央値をまとめる。

## 画面のテスト

ゲームの中身ではなく、画面まわりの決まり（タブが裏から戻ったときの「留守のあいだに」など）を、本物のブラウザで `index.html` を開いて確かめる。Playwright の Chromium を使う。

```
npm install && npx playwright install chromium   # 最初の一度だけ
node --test tools/browser-test.mjs               # 20秒ほど
```

- 時計は偽物に差し替えて、待たずに時間を進める。タブの表と裏は、ページの見え方を差し替えて起こす。
