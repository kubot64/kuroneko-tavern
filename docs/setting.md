# ハルヴァント大陸 設定資料

最終更新：2026年10月7日（鉄の山脈の坑道を追加）

## 世界の手触り

ハルヴァントは、命に値段がついている大陸だ。蘇生は金で買えるが、失敗すれば灰になり、灰の次には何も残らない。

- **冒険者は英雄ではない。** 日銭のために命を売る労働者だ。名誉より金、金より次の朝。
- **死は終わりではなく請求書。** 寺院は祈りではなく料金表で動く。
- **善悪より損得。** 王国も教団も商人も、迷宮から何を持ち出せるかで動く。
- **救いは小さく、個人的なもの。** 酒場の一杯、仲間が出し合った蘇生代、託された遺品。
- **書き方の決まり。** 説明しすぎない。死は淡々と一行で書く。笑いは乾いた冗談として出す。

## 大陸の地理

西:   霧の森（エルフ） / リンデ公国      中央: ラウレンツ王国      東: 灰の荒野（旧エスタリア）・大穴と迷宮都市ロウエン

大陸は中央の王国を囲んで、北に山と神殿、西に森、南に平野と丘と海、南東に草原がある。迷宮は東の灰の荒野、滅んだ王都の跡に口を開けている。

エスタリアの民は、王都が沈んだあとも疫病と飢饉、荒野に降る灰で減り続け、多くは隣の国々へ逃げた。王国やカルセの村には、エスタリア訛りの残る家が今も多い。

## 大陸の外

海の向こうにも国はあるが、ロウエンに届くのは噂と、ごくまれに流れ着く人だけだ。詳しくは語らず、「世界はもっと広い」という手触りだけを残す。

| 土地 | 方角 | 伝わっていること | ロウエンとのつながり |
| --- | --- | --- | --- |
| 東方の島国アズマ | 灰の荒野のさらに東、海の向こう | 反りのある片刃の剣を使う剣士の国。侍の剣術はここから伝わったという | 主を失った浪人が、ときどき海を渡ってくる |
| 砂の大陸ザハル | 南の海の向こう | 砂漠と黄金の都。錬金術と、竜に乗る騎兵団がいるという | セーレの港と交易があり、錬金術師や竜騎士が流れてくる |
| 北の氷海ノルデン | 鉄の山脈の北、凍る海の島々 | 海賊と狩人の部族が暮らす。獣を飼いならす術に長ける | 獣使いや海賊あがりが、帝国を経由してやってくる |

どの国も迷宮のことは噂でしか知らない。大陸の国々は、海の向こうに利権を嗅ぎつけられる前に迷宮を掘り尽くしたい。

## 迷宮と迷宮都市ロウエン

迷宮は、滅んだエスタリアの王都が沈んだ跡の大穴だ。そのほとりにできた街がロウエンで、黒猫亭も銀の杯亭もここにある。

迷宮は王都がそのまま沈んだものなので、広さは中世の大都市が基準になる。人口10万の都の城壁の内側は、およそ3〜4km四方。深い階ほど狭くなる。

| 区画 | 1階あたりの広さ | どんな場所か |
| --- | --- | --- |
| B1〜5 沈んだ城壁と地下牢 | 外周を一周すると5〜6km | 城壁の内側の通路と地下牢。細く長い |
| B6〜10 王都の街区 | 2〜3km四方 | いちばん広い。大通りと広場があり、裏は迷路のような路地 |
| B11〜15 王都の地下水路 | 2km四方ほど | 水路と細い歩廊が網の目のように走る |
| B16〜20 宮廷と墓所 | 1km四方ほど | 宮殿、地下墓所、礼拝堂 |
| B21〜25 魔術師の塔 | 数百m四方 | 塔が地の底へ掘り下げられた部分。狭く、縦に長い |
| B26〜29 儀式の間 | 数百m | 儀式のための広間と回廊。B28Fで黒竜が階段を塞ぐ |
| B30 玉座の間 | 一つの大広間 | 沈んだ王の玉座 |

封鎖前の大部隊が潜れたのは、浅い階の大通りや広場が広かったからだ。ただ、階段や路地、水路では一列になるしかなく、伸びきった隊列を魔物の群れに分断された。二百人の調査隊が呼まれたのも、狭い地下水路のB11Fだった。地図のない街区の1階を、六人の一行が抜けるには半日から1日かかる。

- **成り立ち。** 約80年前のある夜、エスタリアの王都が城壁ごと地の底へ沈んだ。地上に残ったのは、底の見えない大穴と、地下へ続く石の階段だけ。
- **迷宮暦。** 王都が沈んだ年を元年とする。今は迷宮暦81年。迷宮は全部30階。封鎖までの60年でB10Fまでは拓かれたが、B11Fより下は19年のあいだ「封じの門」で閉ざされ、今年ようやく開いた。深層の宝を狙って冒険者が押し寄せ、攻略はこれまでにない速さで進んでいる。
- **澱と蘇生。** 大穴からは「澱（おり）」と呼ばれる魔力が湧いている。蘇生は澱の濃い土地でしか成功せず、王都まで離れれば誰も生き返らない。だから冒険者はこの街を離れられない。
- **六人の掟。** 澱は人の群れに引き寄せられるように魔物を呼ぶ。大勢で潜るほど迷宮は牙をむき、狭い通路では数の利も活かせない。封鎖までの冒険者は何十人もの大部隊で潜っており、そのせいで攻略は遅々として進まず、60年かけてB10Fまでしか行けなかった。200人の調査隊が全滅してようやく、六人以下の一行で潜るのが冒険者の鉄則になった。解禁後の攻略が速いのは、この掘と、封鎖のあいだに解き明かされた転移の石碑、梟の地図がそろったからだ。
- **転移の石碑。** B6F・B11F・B16F・B21F・B26Fには旧王都の石碑が残っている。使い方が解き明かされたのは封鎖のあいだ（迷宮暦70年ごろ）。一度たどり着いた一行は、地上からその石碑へ飛び、帰りも石碑から地上へ戻れる。王都が沈む前、宮廷の魔術師たちが使っていたものだ。
- **鉄床通りの武具屋。** 親方はドワーフのグンター。冒険者が持ち帰った素材が集まるほど、上の品を打てるようになる。
- **梟の地図屋。** ある階を最初に突破した一行の記録を買い取り、しばらくして地図を売り出す。地図のない階は、稼ぐ場所ではなく抜ける場所だ。
- **名のある魔物。** 各階に一体ずつ潜む、由来を持つ魔物。討った一行の名は長く語り継がれる。
- **封じの門を越えた者たち。** 封鎖の19年のあいだにも、門の抜け穴から密かに潜って消えた者がいる。その身内を探しに来る冒険者も少なくない。
- **持ち込まれる話。** 借金を返し終えて店が街に根を張ると、黒猫亭にも噂や頼みごとが持ち込まれるようになる。酒場は話の交差点だ。店主は誰に話を回すかを決めるだけで、引き受けるかどうかは本人が決める。
- **店主の支援。** 黒猫亭の店主は、稼いだ金で常連を支える。出発前の回復薬の差し入れ、地図代や蘇生代の肩代わり、新人への支度の品、見込んだ者への装備の贈り物。恩を感じた冒険者は黒猫亭でよく金を落とすようになり、店はかえって潤うこともある。
- **灰とロスト。** 蘇生に失敗すると体は灰になる。灰からの蘇生にも失敗すると、魂は澱に溶けて消える。寺院はこれを「迷宮に召された」と呼ぶ。
- **金の流れ。** 遺物と素材（ミスリル、星鉄、月長石、竜骨）は同盟の商人が買い取る。王国は探索税を、寺院は蘇生代を取る。冒険者の手元に残るのは、たいてい酒代くらいだ。
- **黒猫亭。** 大穴の西の縁の空き家で、迷宮暦81年、封じの門が開いた月に開いた新しい酒場。店主は若く、開店の金はセーレの両替商から借りた8万G。どの勢力の後ろ盾もなく、席は12しかない。毎月の返済に追われながら常連を支え、店を広げ、老舗の銀の杯亭に追いつくことを目指す。
- **銀の杯亭。** 大穴の東の縁にある大きな酒場で、三十年来ロウエンの頂点にいる。同盟の商人ギルドが出資し、遺物の買い取り窓口も兼ねる。主人のロドリックはギルドの元番頭で、客に上等な装備を貸しつけて稼ぎから取り立てる。客は最初から強いが、借金に追われて無理に深く潜り、よく死ぬ。看板の一行は「白銀の牙」。ロドリックは他の店の腕のいい客を金で引き抜く。
- **裏通りの小さな酒場。** 赤い樽亭、片目の鴉亭など、街には小さな酒場がいくつもある。最深到達を争えるほどの一行は抱えておらず、開いては潰れる。潰れた店の常連が、黒猫亭に流れてくることもある。
- **街のそのほか。** 灰の寺院（教国の出先）、王国の探索管理所（許可と徴税）、遺物市場。

## 勢力と思惑

迷宮から出た金は、商人、寺院、王国、酒場に分け取られ、冒険者の手にはほとんど残らない。

迷宮の金の行き先は4つ：同盟の商人（遺物と素材の買い取り）、寺院（蘇生代）、王国（探索税）、酒場（冒険者の酒代と宿代）。

- **王国**は迷宮を守るためではなく、税を取るために管理している。強い冒険者は騎士に取り立て、他国へ流さないようにする。封鎖の19年のあいだ、探索管理所の役人たちは門の脇の古い抜け穴の通行料をひそかに取っていた。払ったのは、沈んだ故郷の墓を詣でたい荒野の流民たちで、役人は帰り道の分を取らなかった。抜け穴を通った者の名は、どの帳簿にも残っていない（続きものの話「封じの門の抜け穴」で、少しずつ明かされる）。
- **教国と寺院**は蘇生の料金表を決める。灰やロストが本当に事故なのかを疑う者もいる。
- **同盟の商人**は銀の杯亭を通じて冒険者に装備を貸し、稼ぎで返させる。新参の黒猫亭にも、開店資金を貸した両替商を通して金を貸している。どちらが勝っても、同盟は損をしない。
- **帝国**は傭兵を冒険者として潜り込ませ、深層の遺物をひそかに持ち出す。
- **エスタリアの亡霊**は迷宮の中にしかいないが、生き残りの流民はそれを「故国の民」と呼ぶ。

## 迷宮の主と踏破（作り手向けメモ）

最下層にいるのは、エスタリア最後の王「沈んだ王」だ。王を討てば迷宮は踏破されるが、王が討たれても澱は湧き続け、ロウエンの蘇生は終わらない。

- **王の正体。** 疫病と飢饉に追い詰められた王は、宮廷魔術師団と「不死の儀式」を行った。儀式は半分だけ成功し、王は都ごと地の底へ沈み、死ねないまま残った。
- **澱の正体。** 宮廷魔術師たちは、澱を死ねない王から漏れる命だと考えていた。実際の源は、王都とともに沈んだ十万の民の命だ。王の体はそれを留める器にすぎない。蘇生は、沈んだ民の命を切り売りしている。
- **黒竜。** 儀式で王の番犬として縛られた竜。最下層の手前、B28Fの階段を守っている。倒されても、ひと月ほどで澱の中からよみがえる。
- **堕ちた騎士と亡霊。** 王と共に沈んだ宮廷と騎士団のなれの果て。深層ほど、旧王国の貴い者が出てくる。
- **各勢力の本音。** 王国は踏破の名誉が欲しい。教国は踏破で真相が広まるのを恐れている（蘇生の正体が知られるため）。同盟は踏破される前に掘り尽くしたい。帝国は不死の秘術そのものが欲しい。
- **踏破の後。** 澱は王が討たれても湧き続け、寺院の蘇生も変わらず続く。真相が知れ渡れば、人々は蘇生のたびに誰の命を使っているのかを考えることになる。冒険者は迷宮に潜り続け、次の穴（鉄の山脈の坑道の奥）を目指す者も現れる。
- **明かし方。** 真相は一度に語らない。深層で拾う日誌や碑文の断片として、日報に少しずつ出す。

## 鉄の山脈の坑道（作り手向けメモ）

迷宮が踏破されたあとに開く、二つ目のダンジョン。鉄の山脈の東麓、ベルクラント鉱山諸侯領の古い坑道の奥にある。

- **由来。** エスタリアの宮廷魔術師たちは、魔術師の塔を地の底へ掘り下げるために、鉄の山脈のドワーフの坑道王を雇った（迷宮の記録「塔を地の底へ掘り下げよ」）。代価として王家は、王都と坑道を結ぶ対の転移の石碑を坑道王に贈った。坑道と迷宮は、地の底でつながっている。
- **澱が湧いた理由。** 王都が沈むと、石碑の門の向こうから澱が坑道へ流れ込んだ。坑道王は門を閉ざさず、「沈んだ王が死なずにいるなら、我らもその澱を呑めばよい」と、澱を呑んで死ねなくなった。民にも呑ませ、死ななくなった者から言葉を忘れていった。坑道都市はそうして滅びた。
- **澱呑みの坑道王。** 坑道の底の岩の玉座に座る主。沈んだ王の写し鏡で、山の命とエスタリアの命を地の底で混ぜ合わせ、死なずにいる。
- **なぜ今開いたか。** 迷宮の王が討たれたあと、坑道の奥で澱が湧き出しているのが見つかった。坑道の入口で見つかった石碑は、ロウエンの石碑と対になっている。澱が湧くので、坑道でもロウエンの寺院の蘇生が届く。
- **踏破の後。** 坑道王を討っても、大穴が開いている限り、澱は低きへ流れて山の底にも湧き続ける。
- **思惑。** ベルクラントの鉱山諸侯は、坑道の新しい鉱石（黒曜鉄、澱金）を押さえたい。同盟は銀の杯亭を通じて坑道の権利を狙う。ドワーフにとっては、一族の昔の都の跡でもある。
