# 黒猫亭 仕様

いまのゲームの振る舞いをまとめる。世界の設定（国、種族、迷宮の由来など）は [setting.md](setting.md) に書く。

- 書くのは、遊ぶ人から見える振る舞いと、ゲームを決めている決まり（階の数、確率、しきい値など）である。関数名や変数名などの実装の細部は書かない。
- 振る舞いを変えるときは、同じ変更でこの文書も直す。

## 時間と保存

### 時間と日付

- 時間は「刻」の単位で進む。1日は50刻である。
- 「ふつう」の速さでは1刻が2.5秒なので、1日はおよそ2分。
- 暦は迷宮暦81年1月1日から始まる。1年は365日である。年が明けると、冒険者はみな1つ歳をとる（年齢の章を参照）。
- 1刻ごとに、迷宮にいる各一行が1歩ずつ進む。戦闘も1刻に1ラウンドずつ進む。
- 画面上部には、迷宮暦の年月日と時刻、解禁から何日目か、所持金、借金（残っているときだけ）、評判、黒猫亭の最深到達階が出る。

### 速度の切り替え

| ボタン | 動き |
|---|---|
| 止める | 時間が止まる |
| ふつう | 1刻が2.5秒。ページを開いた直後はこの速さになる |
| はやい | ふつうの4倍の速さ |
| 1日放置する | 1日分（50刻）を一気に進める。進めているあいだは「留守のあいだに」の画面が出る |

### 保存と、閉じているあいだの時間

- 進み具合は、ブラウザにひとつだけ保存される。保存されるのは、5刻ごと、店主が操作したとき、ページを閉じるとき、1日放置などの早送りが終わったとき。
- 次に開くと、閉じていた実時間2.5秒ごとに1刻が進んだものとみなされる。ただし10日分（500刻）までである。
- そこに、前回の早送りで進めきれなかった残りを足す。10日の上限は、新しく経過した刻だけにかかり、残りはそのあとで足す。
- 合計が30刻（約75秒）以上か、早送りの残りが1刻でもあれば、「留守のあいだに」の画面を出して合計を進める。
- 早送りの残りがなく、合計が30刻に満たないときは、時間を進めない。
  - 進めているあいだは、進み具合を示す。時が流れ終わるまで「店に戻る」は押せない。
  - 終わると、店をあけていた時間（1分以上のとき）、迷宮で過ぎた日数を出す。
  - 黒猫亭の一行の帰還数と消息不明になった数、ロストした者の数、売上（所持金の増減）を出す。
  - 留守のあいだの知らせを、新しい順に30件まで出す。何もなければ「静かな日々だった。」と出る。
- ページを開いたまま別のタブやアプリに移ったときも、裏にいるあいだは時間を止めて保存し、戻ったときに裏にいた時間を同じように進める（実時間2.5秒ごとに1刻、10日分まで）。
  - 30刻以上なら「留守のあいだに」の画面を出す。30刻に満たないときは、画面を出さずにその分だけ進める。
  - 「止める」にしていたときは進めない。早送りの途中で裏に回ったときは、裏にいた分を早送りに足す。
- 迷宮が30階になる前の古い記録は、別にしまわれる。そのうえで、新しく始め直しになる。

## 冒険者

### 新顔の来店

- 空席があるあいだ、新顔がときどき店に来る。黒猫亭に来る確率は、1刻ごとに1.6%＋評判×0.008%（評判は200までしか効かない）。評判0なら1日に平均0.8人ほど、評判200なら1.6人ほどになる。銀の杯亭には、1刻ごとに1.8%（1日あたり約0.9人）で来る。
- 「傭兵」のお触れが出ているあいだは、来店の頻度が1.8倍になる。そのうち半分はグラウ帝国出身の人間になる。
- 店の評判を聞いて、常連と肩を並べられる者が来ることがある。その割合は50%＋評判×0.2%（評判は200までしか効かないので、最大90%）。この者のレベルは、その店の常連（ロストした者と店を去った者を除く）の平均レベルの前後3以内になる。
- 残りの新顔のレベルは、次の分布で決まる。

| レベル | 確率 |
|---|---|
| 1〜3 | 45% |
| 5〜9 | 35% |
| 11〜15 | 16% |
| 17〜21 | 4% |

- 所持金は40〜120Gに、レベル×15〜40Gを足した額である。
- レベル7以上の新顔は、自前の装備を持ってくる。数はレベル7〜10で0〜1点、11〜16で1〜3点、17以上で2〜4点である。
- 銀の杯亭に来た新顔は、店から装備を1点借りて借金を背負う（店と街の章を参照）。
- 「新人に支度の品を贈る」の方針を取っていると、黒猫亭に来たレベル10未満の新顔に、店主が支度の品を最大2点贈る。
- 黒猫亭に新顔が来ると、出身・経歴・年齢・種族・職業・レベルが知らせに出る。珍しい組み合わせ、レア職、海の向こうの出身、天に愛された者、星回りの悪い者は、目立つ知らせになる。
- 名前は性別に合った名簿から、ほかの冒険者と重ならないように選ばれる。

### 種族

| 種族 | 出やすさ | 得意 | 苦手 |
|---|---|---|---|
| 人間 | 約60% | 経験を積むのが早い | これといった強みもない |
| エルフ | 約8% | 呪文の威力と命中に長ける | 打たれ弱い |
| ドワーフ | 約16% | 頑丈で守りが固く、毒も効きにくい | 呪文の力（MP）が少ない |
| ホビット | 約16% | すばしこく、罠外しと急所突きの名手 | 非力で攻撃が軽い |

### 職業

#### 基本職

職業は種族ごとの比率で決まる。

| 種族 | 戦士 | 侍 | 盗賊 | 僧侶 | 魔術師 |
|---|---|---|---|---|---|
| 人間 | 2 | 1.5 | 1.5 | 2 | 2 |
| エルフ | （珍しい） | 1.5 | 1.2 | 2.5 | 4 |
| ドワーフ | 5 | 1.5 | 0.8 | 2.5 | （珍しい） |
| ホビット | 0.8 | （珍しい） | 5 | 1.5 | 1 |

- 人間以外の新顔は、6%の確率でその種族には珍しい職業になる（エルフの戦士、ドワーフの魔術師、ホビットの侍）。
- この「異例の冒険者」は種族の苦手を克服していて、素質も最低で「有望」になる。

#### レア職

上の珍しい職業に当たらなかった新顔の6%は、レア職になる。4つのレア職は同じ確率で選ばれる。

| レア職 | 特徴 |
|---|---|
| 竜騎士 | ときに竜の息吹で敵を焼き払う |
| 吟遊詩人 | 歌で仲間を奮い立たせ、子守歌で敵を眠らせる |
| 錬金術師 | 爆薬を投げ、戦いのあとは秘薬で仲間を癒やす |
| 獣使い | 相棒の獣（狼・鷹・熊など）が毎ラウンド敵に飛びかかる。相棒には名前がある |

#### 上級職と転職

- 探索から帰るたびに、条件を満たした冒険者は30%の確率で上級職に転職する。
- 転職すると最大体力が3〜8増え、職ごとの上乗せが付く。

| 元の職 | 上級職 | 条件 |
|---|---|---|
| 戦士 | 聖騎士 | レベル20、性格が無謀でも強欲でもない |
| 戦士 | 狂戦士 | レベル20、性格が無謀か強欲 |
| 侍 | 剣聖 | レベル24、討伐200 |
| 盗賊 | 忍者 | レベル22、罠解除15 |
| 僧侶 | 司教 | レベル22、蘇生された回数が3回未満 |
| 魔術師 | 魔導士 | レベル24 |

### 出身と経歴

- 出身は種族ごとの重みで選ばれる。
  - 人間：大陸の各国から来る。
  - エルフ：多くは霧の森から来る。
  - ドワーフ：多くは鉄の山脈から来る。
  - ホビット：多くは麦穂の丘から来る。
- 海の向こうの出身（東方の島国アズマ、砂の大陸ザハル、北の氷海ノルデン）はまれである。それぞれ、特定の職業と結びつきやすい。
  - アズマ：侍、剣聖
  - ザハル：錬金術師、竜騎士
  - ノルデン：獣使い
- 経歴は出身ごとに用意されていて、来店時のレベルで3段階に分かれる。
  - レベル1〜4：駆け出しの身の上（家出した子、見習いなど）
  - レベル5〜10：前歴のある者（元兵士、用心棒など）
  - レベル11以上：名のある者（元騎士、隊長など）

| 素質 | 出やすさ | 育ち方 |
|---|---|---|
| 凡庸 | 約28% | 経験の入りが0.8倍 |
| 並 | 約47% | 標準 |
| 有望 | 約19% | 経験の入りが1.25倍、レベルアップ時の体力の伸びが大きい |

### 年齢

#### 来店時の年齢

年齢は種族ごとに「若手枠」と「年長枠」の範囲がある。

| 種族 | 若手枠 | 年長枠 |
|---|---|---|
| 人間 | 15〜30歳 | 31〜62歳 |
| ホビット | 18〜40歳 | 41〜95歳 |
| ドワーフ | 25〜90歳 | 91〜190歳 |
| エルフ | 30〜180歳 | 181〜420歳 |

年長枠に入る確率はレベルで変わる。

| 来店時レベル | 年長枠の確率 |
|---|---|
| 1〜10 | 5% |
| 11〜16 | 17% |
| 17以上 | 37% |

- 若手枠では、レベルが高いほど年齢が上に寄る。
- 年長枠では、枠の若い側（人間なら30代）に寄りやすい。レベルが高いほど、少し上まで伸びる。40〜50代は多くない。

#### 人間換算

- 人間以外は「人間でいえば何歳ほど」で表す。
  - 若手枠の年齢は、人間の15〜30歳に比例で当てはめる。
  - 年長枠の年齢は、人間の31〜62歳に比例で当てはめる。
  - 換算年齢は13歳を下回らない。
- 口調、一人称、夢の選ばれ方、老いによる引退は、すべてこの人間換算の年齢で判断する。

#### 毎年の加齢

- 1年（365日）が明けるたびに、店を去っていない冒険者とロストしていない冒険者が、実年齢でひとつ歳をとる。寺院で眠っている者も含む。
- 長命な種族ほど、人間換算の年齢はゆっくり進む。

### 性別

- 男と女が半々で出る。
- 性別は一人称と、一部の夢の文面に影響する。

### 性格

- 来店時に、慎重・普通・無謀・強欲・臆病のどれかが同じ確率で選ばれる。
- 性格は、リーダーへの選ばれやすさ、潜る深さ、引き返す判断、仲間との口論のしやすさに効く。
- 性格は出来事で変わることがある。

| きっかけ | 変化 |
|---|---|
| 一緒に5回以上潜った仲間がロストした | 無謀か強欲なら、50%で慎重になる |
| 同じ人が3度死にかけた | 無謀・普通・強欲なら60%で変わる。無謀は普通になり、普通と強欲は慎重になる |
| 初めて所持金が50000Gを超えた | 強欲でなければ、35%で強欲になる |
| 名のある魔物を討った | 臆病や慎重な者は、自信がついて変わることがある |

変わったことは、冒険者の手帳の「変わったこと」に日付つきで残る。

### 口調と一人称

- 口調は普通・丁寧・ぶっきらぼう・無口・陽気・古風・商人言葉・田舎なまりの8種である。出身、職業、年齢、性格、癖で選ばれやすさが変わる。
- 一人称は、種族・性別・年齢・性格・口調で決まる。話すたびにそのときの年齢で決まるので、歳をとると変わることがある（人間の男は55歳で「俺」から「わし」に、女は40歳で「あたし」から「私」になる）。
- 口調ごとの選ばれやすさ、語尾の変わり方、一人称の決まり方は「画面と語り」の章の「口調」に書く。

### 口癖・好物・怖いもの・癖

#### 口癖

- 24種類から1つ選ばれる。酒場の会話や土産話の最後に、ときどき添えられる。
- 口癖は出来事で変わることがある（「画面と語り」の章の「口調や口癖が変わるとき」を参照）。

#### 好物

- 18種類から1つ選ばれる。酒場の会話や土産話に出てくる。

#### 怖いもの

- 半数の冒険者が、怖いものを1つ持つ。種類は次の10個である。
  - 魔物：蜘蛛・亡霊・蛇・竜・死体・獣
  - 場所：水・暗闇・狭い所・高い所
- 怖い魔物と出会うと、青ざめることがある。戦闘中は命中が15%下がり、ときにすくんで動けなくなる。
- 怖い場所にいるあいだは、命中が下がる。
  - 水：王都の地下水路で7%
  - 狭い所：沈んだ城壁と地下牢で7%
  - 高い所：魔術師の塔で7%
  - 暗闇：地図のない階で6%

#### 癖

- 酒好き・甘党・験担ぎなど12種類から1つ選ばれる。
- 迷宮での独り言、酒場での様子、土産話に出る。夢の選ばれ方にも効く。

### 得意と不得意

#### 種類

| 得意 | 不得意 |
|---|---|
| 怪力、頑健、俊足、強運、鷹の目、器用、博識、信心深い、不屈、毒に強い、早熟、大器晩成、料理上手、人望、夜目 | 鈍足、虚弱、不器用、近眼、不運、病弱、覚えが悪い、浪費家 |

#### 数の決まり方

- 天に愛された者：素質が天賦なら20%で、それ以外は1%でなる。得意を3〜4個持ち、不得意を持たない。
- 星回りの悪い者：2%でなる。不得意ばかり3個持ち、得意を持たない。
- それ以外の冒険者は次のとおりである。
  - 得意：0個が15%、1個が60%、2個が25%。有望は40%で1個増え、天賦は必ず1個増える。
  - 不得意：0個が45%、1個が47%、2個が8%。凡庸は30%で1個増える。

#### 選ばれ方

- 正反対のもの（俊足と鈍足、頑健と虚弱など）は一緒に持たない。
- 種族と職業で出やすさが偏る。
  - ドワーフ：頑健、毒に強い、鈍足が出やすい。
  - エルフ：鷹の目、博識、夜目、虚弱が出やすい。
  - ホビット：器用、強運、俊足、料理上手が出やすい。
  - 人間：早熟、人望が出やすい。
  - 僧侶：信心深いが出やすい。
  - 戦士：怪力、頑健が出やすい。

#### 不得意の克服

探索から帰るたびに、条件を満たした不得意を、低い確率で克服することがある。克服するとその不得意は消える。一部は12%の確率で、反対の得意に変わる。

| 不得意 | 克服の条件 | 変わることがある得意 |
|---|---|---|
| 鈍足 | レベル16 | 俊足 |
| 虚弱 | レベル14（体力も増える） | 頑健 |
| 不器用 | 罠解除15、またはレベル22 | 器用 |
| 近眼 | レベル20 | ― |
| 病弱 | 毒を8回受ける、またはレベル24 | 毒に強い |
| 覚えが悪い | レベル20 | ― |
| 浪費家 | お金を貯める夢をひとつ叶える | ― |
| 不運 | レベル30 | 強運 |

### 夢

#### 夢の持ち方

- 冒険者は来店時に夢をひとつ持つ。
- 夢の種類は、職業・出身・種族・年齢・性格・癖で偏る。出身や職業が合わないと持たない夢もある。
- 同じ店で同じ種類の夢を持つ者が多いほど、その夢は選ばれにくくなる。全員の中で同じ文面の夢は避ける。
- 夢の文面は、種類ごとにいくつかある書き方から1つ選ぶ。入れる言葉（誰のため、どこで、何を）もそのとき決まる。
- 一度叶えた種類の夢は二度と持たない。
- 夢の判定は、探索から帰って酒場に戻ったときに行う。
- 夢が叶うと、次の夢を抱くまで3〜8日の間が空く。そのあいだ手帳には「次の夢を探している」と出る。間が明けたあとの帰還で、新たな夢を抱く。
- お金を貯める夢では、叶えるとその額を使う。ただし「財産を築く」と「余生の蓄え」は、貯金が減らない。
- 必要な額は本人の潜れる深さに応じて決まり、夢ごとに下限がある。
- 叶ったときの知らせと店を去る理由は、選ばれた夢の文面に合わせる（「画面と語り」の章を参照）。

### 二つ名

- 探索から帰るたびに手柄を調べ、条件を満たすと二つ名が付く。
- 二つ名には格がある。今より高い格の手柄を立てると、新しい二つ名に変わる。

| 格 | 手柄 |
|---|---|
| 1 | 討伐80、罠解除8、蘇生3回 |
| 2 | B18F到達、名のある魔物の討伐、蘇生5回 |
| 3 | 討伐500、黒竜討伐、伝説の品を装備 |
| 4 | 迷宮の主を討つ |

- 候補は手柄の種類に合わせて出る。性格・職業・得意・出身・よく倒す魔物・武器・討った名のある魔物・伝説の品の名などを使う。
- ほかの冒険者と同じ二つ名にはならない。
- 二つ名が付くと、名前の前に「」付きで出る。

### 絆

- 同じ店の冒険者どうしが一緒に探索から帰るたびに、二人の絆が1ずつ深まる。帰り道で倒れて運ばれた者も含む。
- 絆には二人の出来事が残る。担いで帰った、迷宮で蘇生した、癒やした、ともに死にかけた、名のある魔物を仕留めた、一番乗りした、口論した、などである。
- 絆の効き目は次のとおりである。
  - 一行を組むとき：リーダーは絆の深い者から仲間を選ぶ。
  - リーダーが抜けたとき：前のリーダーと絆が5以上の者は、少し後を継ぎやすい。
  - 酒場の会話：絆の深い二人ほど話しやすい。思い出話をし、8回以上なら「腐れ縁」の話をする。
  - 土産話：いちばん絆の深い仲間の話をする。
- 一緒に3回以上潜った仲間がロストしたり、店を去ったり、よその店に移ったりすると、酒場でその仲間の話をする。
- 一緒に5回以上潜った仲間がロストすると、残った者が変わることがある。無茶をしなくなる、口数が減る、口癖を真似る、のいずれかである。

### 引退（店を去る）

冒険者が店を去るきっかけは次の4つである。

1. 老い：探索から帰って酒場に戻ったとき、人間換算55歳以上なら12%の確率で、老いを感じて身を引く。
2. 夢：叶えた夢によっては、必ず、または一定の確率で店を去る（夢の各表を参照）。
3. 身内の救出：消えた身内を生きて見つけたとき、50%で身内と故郷へ帰る。席が埋まっているときは、この50%にかかわらず、本人が酒場に戻れていれば身内と故郷へ帰る（席の上限が優先する。「身内探し」を参照）。
4. 弔い：身内の形見だけを見つけたとき、35%で弔いの旅に出る。

- 去る者が一行に属していたら、装備は使える仲間に託される。
- 去った者は手帳に「店を去った」と残る。年齢はそこで止まる。
- ロストとの違い：ロストは迷宮に呑まれて二度と戻らないことである。店を去った者は、残った仲間の話題に「今ごろどうしているか」として出る。

## 一行と迷宮

### 一行の結成

- 酒場ごとに、各刻12%の確率で新しい一行の結成が試みられる。迷宮に出ている一行が酒場ごとに6組に達していれば結成しない。
- 一行に入っていない待機中の冒険者が3人以上いることが条件である。
- **リーダー**は「リーダーの資質」が高い者から選ばれる。7割は最も資質の高い者が、3割は上位4人の誰かがなる。資質を上げる要素は次のとおり。
  - レベルが高い
  - 得意「人望」を持つ（大きく上がる）
  - 性格。慎重 > 普通 > 無謀 > 強欲 > 臆病 の順に有利で、臆病は大きく不利になる
  - 探索の回数が多い
  - 人間でいえば30歳以上
- **仲間の選び方**
  - リーダーと実力（レベルの半分）の差が3以内の者を優先する。その中では、リーダーと一緒に潜った回数が多い者ほど優先する。
  - 実力の近い者だけで6人に届かないときは、レベル差があっても、実力の近い順に足して6人にする。こうしてできた一行は実力にばらつきがあるので、たいてい「腕を磨く」方針で潜る（「その回の方針」を参照）。
  - 前衛、癒し手、呪文や爆薬や歌の使い手、盗賊、もう一人の前衛、の順に役割をそろえようとする。足りない枠は残りから無作為に埋める。
- **人数**は基本6人で、最低3人である。6人そろわない場合、結成されるのは3%の確率でしかない。
- 並びは前衛が前に来る。敵の攻撃は前の3人に3倍の重みで集まる。
- 一行の名前は、結成したときのリーダーの出身・職業・種族から付けられる。
  - 出身・職業・種族には、それぞれ名前に使う言葉がある（帝国なら「鉄兜」「黒鷲」、ドワーフなら「黒鉄」「大槌」、盗賊なら「合鍵」「忍び足」など）。どこの出でも使う言葉（「樽」「銀貨」など）もある。言葉の選ばれやすさは、出身3、職業2、種族2、どこにでもある言葉0.5の割合。人間には種族の言葉がない。
  - 名前は、頭の言葉と結び（「〜傭兵団」「〜一族」「〜一味」「〜の環」など）でできる。結びは6割の確率で頭の言葉と同じ出どころから選び、残りはリーダーの出身・職業・種族とどこにでもある結びのどれかから選ぶ。
  - 3割の確率で、出身やどこにでもある名前の一覧から、そのまま使える名前（「第七傭兵団の残り」「二度目の朝食の会」など）を選ぶ。
  - 一度使った名前は、その一行がいなくなっても二度と使わない。いまいる一行の名前に含まれる言葉は、頭の言葉に使わない。
  - 使える名前が見つからないときは、「リーダーの名前＋隊・2」のように番号を付ける。
  - 銀の杯亭の看板の一行など、最初から名前が決まっている一行もある。

### 出発と帰還

#### 街での休みと再出発

- 帰還した一行は14〜24刻休む。そのあと再出発の支度に入る。
- 支度の流れは次のとおり。
  1. 別の酒場に移った者は外れる。
  2. リーダーがいなくなっていれば、後継ぎを決める（後述）。
  3. 7人以上いれば、レベルの低い順に外れる。
  4. 6人に満たなければ、待機中の冒険者から補う。補うのは、リーダーとの実力差が6以内の者である。一緒に潜った回数が多い者ほど、実力の近い者ほど優先する。
- 待機中の者が3人以上いて、全員がそろえば出発する。
- 寺院で眠る者まで数えて6人いるときは、その者が蘇生して戻り、6人そろうまで出発しない。蘇生に失敗してロストすれば、6人に届かなくなるので、次の決まりに移る。
- 6人に届かないときは、全員がそろわなくても、150刻待てば待機中の者だけで出発する。リーダーが不在の場合は300刻待つ。
- 待機中の者が3人に満たないまま450刻が過ぎると、一行は「仲間がそろわず」解散する。
- 出発のとき、転移の石碑を使って途中の階から潜りはじめることがある（「迷宮の構造」を参照）。

#### その回の方針

出発時に、その回の方針が次の3つから決まる。

| 方針 | 内容 |
|---|---|
| 腕を磨く | 安全な深さより2階ほど浅い階までにとどめる。実力のばらつきが大きいとき、前回に死者が出たとき、リーダーが慎重か臆病のとき（半々）に選ばれやすい |
| 深く潜る | いつもより一歩深くまで踏み込む。理由がある場合と、リーダーが無謀なために「いけるところまで」潜る場合がある |
| ふつう | 安全な深さまで潜る |

「深く潜る」理由には次のものがある。

- 相手の酒場に最深記録で負けている
- 一番乗りを狙う
- 王国の報奨金を狙う
- 仲間の夢の階まで行く
- 仲間の仇の魔物を探す

理由を持って深みを目指した一行が戻らなかったときは、その理由が知らせで語られる。

#### 性格ごとの深さ

- 一行の「安全な深さ」は、仲間の実力の平均とリーダーの性格で決まる。実力の平均は、最も弱い者の実力に2.5を足した値を上限とする。
- 下の階へ降りるには、次の条件をすべて満たす必要がある。
  - その階をある程度歩き回った（地図があれば6歩、なければ10歩＋階の数。B11Fなら21歩、B30Fなら40歩）
  - いまの階が安全な深さより浅い
  - 体力に十分な余裕がある
  - 30%の運に当たる

| 性格 | 引き返す体力の目安 | 深さの傾向 |
|---|---|---|
| 臆病 | 65%を切ったら | 最も浅い |
| 慎重 | 55% | 浅め |
| 普通 | 42% | 標準 |
| 強欲 | 35% | やや深い |
| 無謀 | 22% | 最も深い |

#### 引き返す条件

探索中に次のどれかに当たると、一行は帰り道に入る。

- 一行の体力の合計の割合が、性格の目安を下回った。平均レベルが低い一行は早めに帰る。深く潜る理由を持つ一行と、借金を抱えた銀の杯亭の一行は粘る。
- 仲間が倒れた。または誰かの体力が2割を切った（リーダーが無謀なら引き返さない）。
- 生きている者が半数以下になった。
- 歩いた数が160歩を超えた。腕を磨く回は220歩。
- 癒し手の呪文が尽き、体力にも余裕がない。
- ほかの一行の遺体を担いでいる。
- 店主が伝書鳩で撤退を命じた（黒猫亭の一行のみ）。

帰り道では、30%の確率で1階ずつ上る。石碑のある階にいれば、石碑に触れて一気に地上へ戻る。

### 後継ぎ・解散・仲間割れ

- **後継ぎ**：街での支度のとき、リーダーがいなくなっていることがある。理由はロスト、引退、他の酒場への移籍である。残った者が2人以上いれば、最も資質の高い者が後を継ぐ。継げる確率は55%である。その者が「人望」を持っていれば30%、前のリーダーとの絆が深ければ（一緒に潜った回数が5回以上）10%上がる。継げなければ一行は解散する。
- **解散**：後継ぎが立たないとき、仲間がそろわないまま450刻待ったときに起こる。全員が一行を離れ、解散は知らせで告げられる。
- **仲間割れ**：帰還のたびに、リーダー以外の一人ひとりについて揉めるかどうかを判定する。
  - 確率はふだん1.2%である。性格がぶつかる組み合わせだと7%になる。
    - リーダーが無謀で、仲間が慎重か臆病
    - リーダーが臆病で、仲間が無謀
    - 仲間が強欲で、稼ぎが少なかった
    - リーダーが強欲で、仲間が慎重
  - その回に死者が出ていれば確率は2.5倍になる。リーダーが「人望」を持っていれば0.4倍になる。
  - 揉めた者は半々の確率で一行を抜ける。揉めるのは1回の帰還で1人までである。揉めた記憶は二人の絆に残り、酒場の会話にも出てくる。

### 迷宮の構造

迷宮は全30階である。区画は次の7つに分かれる。

| 階 | 区画 |
|---|---|
| B1〜B5F | 沈んだ城壁と地下牢 |
| B6〜B10F | 王都の街区 |
| B11〜B15F | 王都の地下水路 |
| B16〜B20F | 宮廷と墓所 |
| B21〜B25F | 魔術師の塔 |
| B26〜B29F | 儀式の間 |
| B30F | 玉座の間 |

- **封じの門**：B10Fの下にある。ゲーム開始時のお触れで開かれ、B11Fより下の探索が解禁される。B10Fまでは昔の大部隊が切り開いた階で、はじめから地図がある。銀の杯亭の最深記録はB10Fから始まる。
- **前人未踏の階**：B11F以降で、まだ誰も通り抜けていない階である。出る魔物が一段強くなる。最初に足を踏み入れた一行は知らせで讃えられ、酒場の評判が上がる。罠で飛ばされて着いた場合も同じに扱い、知らせには「罠で飛ばされ、」と添える。最深記録、王国の報奨金、二つ名の手柄も、階段で降りたときと同じに数える。
- **転移の石碑**：B6、B11、B16、B21、B26Fにある。出発時、一行はB1Fから歩かずに石碑で降りられる。使えるのは、自分たちが到達したことがあり、かつ安全な深さ（腕を磨く回はその上限）を超えない最も深い石碑である。帰りは石碑のある階から一気に地上へ戻れる。
- **地図**：梟の地図屋が売る（売り出しと値段は「店と街」の章の「地図屋」を参照）。地図があるかどうかで、探索は次のように変わる。

| | 地図あり | 地図なし |
|---|---|---|
| 次の階へ降りられるまで | 6歩 | 10歩＋階の数（深いほど広く、歩き回る） |
| 戦闘の経験値と金 | 通常 | 7割 |
| 不意打ち | 受けない | 20%（前人未踏の階では35%） |
| 宝箱が出る確率 | 42% | 30% |
| 罠の外しやすさ・罠の痛さ | 外しやすく、痛みは軽い | 外しにくく、痛みは重い（前人未踏の階ではさらに重い） |
| 宝箱から品が出る確率 | 通常 | 6割 |
| 戦いを避けて身を潜める | しない | できる |

- 地図のない階では、敵に会う確率がやや下がる。前人未踏の階を除く。
- 地図のないB4F以降に着いたとき、呪文ミトオシの使い手がいれば60%の確率で唱える。唱えると、その探索のあいだその階に地図があるものとして扱う。
- **記録の断片**：B12〜B29Fに8つある。その階より深くを歩くと、ときどき見つかる。見つかるのはそれぞれ一度きりで、沈んだ王都の真相を語る。
- 遠見の水晶に映る記録は、B6F以降で文字がかすれはじめ、深いほどかすれがひどくなる（「画面と語り」の章を参照）。

### 探索中の出来事

探索中は1歩ごとに、おおむね次のどれかが起こる。

- 魔物と出会う。約24〜30%。
- 同じ階で全滅した一行を見つける。
- 他の一行とすれ違う。言葉を交わし、土産話の種になる。
- 記録の断片を見つける。
- 先へ進む、または下の階へ降りる。

帰り道でも、18%の確率で魔物に出会う。

### 戦闘

#### 流れ

1. 魔物が現れる。数は1〜数体で、浅い階ほど多い。魔物の正体は6割の確率でわかり、わからなければ見た目だけが示される。得意「博識」を持つ者がいれば必ずわかる。2ラウンド目からは正体がわかる。
2. 地図のない階で探索中に初めて出会った魔物なら、戦いを避けようとすることがある。避けようとする確率は45%（無謀なリーダーなら15%）で、そのうち65%で避けられる。
3. 帰り道の戦闘では45%の確率で逃げようとする。臆病か慎重なリーダーは、体力が目安を下回ると60%の確率で逃げようとする。逃走の成功率は60%で、仲間に「俊足」がいれば上がり、「鈍足」がいれば下がる。
4. 不意打ちを受けると、魔物が先に動く。
5. 一行が順に動く。そのあと、生き残った魔物が反撃する。これを1刻に1ラウンドずつ繰り返す。
6. 魔物を全滅させると、経験値と金を得る。素材を拾うこともあり、宝箱が出ることもある。

#### 一行の動き

各自は、次のうち最初に当てはまることをする。

- 癒し手は、傷ついた仲間を呪文で癒やす。毒を受けた仲間がいれば毒を消す。
- 強敵（名のある魔物、黒竜、沈んだ王、強い変異種、深い階の群れ）が相手なら、守りの呪文マモリを張る。
- 仲間の体力が3割を切ったとき、差し入れの回復薬があれば使う。最大体力の4割を回復する。
- 攻撃呪文の使い手は、敵が2体以上いるときに呪文を唱えることが多い。威力と相性を比べて呪文を選ぶ。
- それ以外の者は武器で斬りかかる。

#### 呪文

| 呪文 | 効果 | 使い手 |
|---|---|---|
| イヤシ | 仲間ひとりを癒やす | 僧侶・司教・聖騎士 |
| ゼンカイ | 仲間全員を癒やす（3人以上が傷ついたとき） | 僧侶Lv17〜・司教Lv15〜 |
| ドクケシ | 仲間ひとりの毒を消す | 僧侶・司教・聖騎士 |
| マモリ | その戦闘のあいだ全員の守りを上げる | 僧侶・司教・聖騎士（Lv7〜） |
| ダッシュツ | 一行を地上へ戻す | 僧侶Lv19〜・司教Lv15〜・聖騎士Lv23〜 |
| ヨミガエリ | B16F以降で倒れた仲間をその場で蘇らせる | 僧侶Lv27〜・司教Lv23〜 |
| ホノオ／ゴウカ | 敵の群れを焼く。ゴウカは強力版 | 魔術師・魔導士・司教・侍・剣聖 |
| コオリ | 群れを凍らせる。30%で1ラウンド動きを止める | 魔術師Lv5〜・司教Lv9〜・魔導士 |

| ミトオシ | 地図のない階の道筋を見通す | 魔術師Lv15〜・司教Lv19〜・魔導士 |

- 魔物には属性の相性がある。亡霊や虫には炎がよく効く。竜には炎がほとんど効かず、氷がよく効く。石や鉄の魔物、騎士には雷がよく効く。相性は、魔物の正体がわかっているときだけ呪文選びに使われる。
- **ダッシュツ**は次の場面で使われる。
  - 戦闘中に、生き残りが半数以下になったか、体力が25%を切ったとき。沈んだ王との戦いでは使わない。
  - B6F以降の帰り道で、体力が35%を切ったとき。
- 職業ごとの特技もある。
  - 吟遊詩人は勇ましい歌で一行の攻撃を上げ、子守歌で敵を眠らせる。
  - 錬金術師は爆薬で群れを攻撃し、戦いのあとに秘薬で仲間を癒やす。
  - 竜騎士はときどき竜の息吹で群れを焼く。
  - 獣使いの相棒は毎ラウンド敵に飛びかかる。
  - 狂戦士はときどき二度斬りかかる。

#### 会心

- 侍、盗賊、剣聖、忍者と、会心を高める装備を持つ者は、ときどき敵の首をはねて一撃で倒す。
- 会心の確率は、職業、装備、レベル、種族（ホビット）、得意「器用」「強運」で上がる。
- 名のある魔物、黒竜、沈んだ王の首ははねられない。

#### 眠り

- 魔術師のネムリは、敵が3体以上いて、浅い階（B6Fまで）の戦いで使われる。1体ずつ6割の確率で、2ラウンド眠らせる。
- 眠った敵は動かない。眠った敵への攻撃は当たりやすく、ダメージも2倍になる。
- 黒竜と沈んだ王は眠っていても動く。

#### 魔物の攻撃

- 魔物の攻撃は前の3人に集まりやすい。不得意「不運」を持つ者は狙われやすい。
- 命中のしやすさは、守り、回避、階の深さ、地図の有無で変わる。
- 特殊な攻撃を持つ魔物がいる。
  - **毒**：受けると2刻ごとに体力が1ずつ減る。毒で体力が1より下がることはない。毒は帰還すると消える。
  - **吸精**：レベルを2つ吸い取る。
  - **炎の息**：全員を焼く。炎を防ぐ装備で軽くできる。
  - **呪文**：全員を傷つける。

#### 変異種

魔物の15%は変異種として現れる。

| 変異 | 強さ | 経験値 |
|---|---|---|
| 手負いの | 体力6割・攻撃やや弱い | 0.8倍 |
| 年老いた | 体力・攻撃とも8割 | 0.9倍 |
| 若い | やや弱い | 0.8倍 |
| 飢えた | 攻撃が強い | 1.1倍 |
| 凶暴な | 体力・攻撃とも強い | 1.4倍 |
| 巨大な | 体力1.6倍 | 1.5倍 |
| 群れの長の | 体力1.8倍・攻撃1.4倍 | 2倍 |
| 澱にまみれた | 体力1.5倍・攻撃1.35倍（B15F前後から） | 1.8倍 |

### 罠と宝箱

- 戦闘に勝つと、宝箱が出ることがある。地図があれば42%、なければ30%。
- 盗賊がいなければ、慎重か臆病なリーダーは宝箱を開けずに進む。
- 開けるのは盗賊で、盗賊がいなければ誰か一人が開ける。罠を外せる確率は、盗賊のレベル、得意や不得意、種族（ホビット）、装備、地図の有無で上がり、階が深いほど下がる。盗賊が罠を外すたびに、外した数が記録される。
- 失敗すると罠が作動する。

| 罠 | 効果 |
|---|---|
| どくばり | 開けた者が傷を負い、毒を受ける |
| いしつぶて | 全員が傷を負う |
| ばくだん | 全員が大きな傷を負う |
| まひガス | 全員が少し傷を負う |
| テレポーター | 1階上〜2階下のどこかへ飛ばされる。まだ誰も突破していない階の下へ飛ばされることもある。黒竜が生きているあいだはB28Fより下へは飛ばない |

- 宝箱には金が入っている。深い階ほど多い。ときどき装備品も入っている。深い階ほど、地図がある階ほど、得意「強運」の者が開けるほど出やすい。

### アイテムと装備

- 装備の枠は、武器・盾・頭・胴・装飾の5つである。両手武器を持つと盾は持てない。装備できる品は職業ごとに決まっている。
- 手に入れた品は、一行の中でいちばん強くなる者が身につける。外れた古い品は、次に役立つ仲間へ順に譲られる。誰も使えない品は売って、稼ぎに足す。
- 品の材質と強さは、拾った階の深さで7段階に分かれる。品には一点ものの名前が付く。
- **伝説の品**は9点あり、世界にひとつずつしかない。B11F前後より深い宝箱から、ごくまれに出る。名のある魔物が落とす専用の品もある。
- 「不死鳥の羽根」を身につけた者は、倒れたとき一度だけ体力の半分で立ち上がる。羽根は燃え尽きる。
- 戦いのあと、素材（鉱石など）を拾うことがある。素材は帰還時に武具屋へ卸し、代金は一行で分ける。
- 帰還後の買い物は「店と街」の章の「武具屋」を参照。

### 死亡と蘇生

#### 倒れたとき

- 体力が0になった仲間は迷宮の中で倒れる。倒れた仲間は一行に担がれたまま進む。
- 得意「強運」を持つ者は、12%の確率で体力1で踏みとどまる。

#### 全滅

- 一行の全員が倒れると全滅し、その一行は消息不明になる。
- 遠見の水晶で見ていれば、最期はすぐに知らされる。見ていなければ、しばらくたってから「予定を過ぎても戻らない」と知らされる。黒猫亭なら15刻後、銀の杯亭なら25刻後。一度消息が知れた一行でも、また潜ったあとで全滅したときは、同じように知らせる。
- 同じ階を通る他の一行が、全滅した一行を見つけることがある（「他の一行の発見」を参照）。遺体が見つかって運ばれているあいだも、その一行は消息不明のままである。街に着くまえに、別の仲間を集めて潜り直すことはない。
- 遺体が街に着くと、いつもの休息と支度に戻る。生き返った者も、足りなければ待機中の者も、そこで仲間に入る。生き返らなかった者が多く、仲間がそろわなければ解散する。
- 1000刻（20日）たっても誰にも見つけられなければ、全員がロストとなり、記念碑に名が刻まれる。遺体を運んでいる途中は、この20日を数えない。運び手も全滅したときは、遺体は再び迷宮に残り、そこから20日を数える。

#### 寺院での蘇生

- 帰還すると、倒れた者は寺院に運ばれる。蘇生代、成功率、誰が払うかは「店と街」の章の「寺院の費用と店の立て替え」に書く。
- 灰から戻った者は、25%の確率で人が変わったように静かになる。
- **ヨミガエリ**は、B16F以降で戦闘に勝ったあとに唱えられる。成功率は45%＋使い手のレベルに応じて上がり、最大85%。成功すれば、倒れた仲間は体力の3分の1でその場で起き上がる。失敗すると灰になり、灰のまま運ばれる。

#### ロストと記念碑

- ロストした者は二度と戻らない。名前、職業、レベル、倒れた階、倒した相手が記念碑に刻まれる。
- ロストする道は2つある。灰からの蘇生に失敗したときと、全滅した一行が20日のあいだ見つからなかったときである。

### 名のある魔物

- B1〜B30Fの各階に1体ずつ、名のある魔物がいる。その階で魔物に出会うたびに、0.4%の確率で現れる。
- 一度討たれた名のある魔物は二度と現れない。
- 名のある魔物は各階に1体きりなので、ある一行が戦っているあいだは、同じ階の別の一行の前には現れない。
- 体力が多く、B12F前後より深いものは1ラウンドに2回動く。首をはねることはできず、戦いを避けることもできない。逃げることはできる。
- 討つと、魔物ごとに決まった褒美が手に入る。

| 褒美 | 内容 |
|---|---|
| 大金 | 多額の財宝 |
| 経験 | 一人ひとりに大きな経験値 |
| 素材 | 武具屋の新しい品の素材を大量に |
| 伝説の品 | その魔物だけが持つ装備 |

- 討った者は二つ名を得やすくなる。
- B30Fの名のある魔物は、沈んだ王が討たれたあとにしか現れない。

### 黒竜

- B28Fで階段の前をふさぐ門番である。黒竜が生きているあいだは、B28Fから下へ降りようとすると必ず黒竜と戦う。
- 体力650、1ラウンドに2回動く。40%の確率で黒い炎の息を吐き、全員を大きく焼く。炎の息を防ぐ装備で軽くできる。
- 眠らず、首をはねられることもない。
- 討つと、その一行はすぐに下へ進める。黒竜は25〜35日後に澱の中からよみがえり、また階段をふさぐ。
- 竜殺しの大剣は、竜とキメラに倍の傷を負わせる。

### 沈んだ王

- B30F玉座の間の主である。まだ誰も討っていないうちは、B30Fに着いたとき、およびB30Fで魔物に出会ったときの相手は、必ず沈んだ王になる。
- 体力900、1ラウンドに2回動く。
  - 40%の確率で古い呪文を唱え、黒い炎で全員を焼く。
  - 攻撃でレベルを吸い取ることがある。
  - 首をはねることはできず、戦闘中にダッシュツで逃げることもできない。
- 討った一行は迷宮を踏破したことになる。一人ひとりに王国から107800Gが授けられ、全員が踏破者として二つ名を得る。黒猫亭の一行なら、店にも祝い金50000Gが届き、評判が50上がる。
- 王を討っても澱は湧き続け、迷宮と寺院の営みはそのまま続く。

### 救出イベント

#### 身内探し

- 夢「封じの門を越えて消えた身内を探す」を持つ冒険者がいる。探す相手は兄、姉、弟、父、師匠、幼なじみのいずれかである。
- その冒険者がいる一行が身内のいる階（B11〜B16F付近）を探索すると、1歩ごとに1.2%の確率で手がかりにたどり着く。
- **1割の確率で、身内を生きて見つけ出す。** 一行はすぐに帰路につく。帰還後、探していた本人は半々の確率で身内とともに故郷へ帰り、店を去る。去らなかった場合、席が空いていれば、救い出された身内がレベル3〜11の新しい冒険者として同じ店の客になる。種族と出身は本人と同じで、年齢は続柄に合わせて決まる。席が埋まっているときは客にならない。本人が酒場に戻れていれば、二人で故郷へ帰る。本人が寺院で眠ったまま、灰のまま、あるいはロストしていれば、救い出された身内だけが故郷へ帰る。
- **残りの9割では、形見だけが見つかる。** 形見はペンダントや日記などである。夢はそこで終わり、35%の確率で、次に帰ったときに本人は弔いの旅に出て店を去る。

#### 他の一行の発見

- 探索中や帰り道で、同じ階で全滅した一行を見つけることがある。店主が死体回収の依頼を出していれば、見つかりやすくなる。すでに誰かが遺体を運んでいる一行は、ここには入らない。
- 見つけた一行は遺体を担いで連れ帰り、すぐに帰路につく。依頼があれば、帰還時に報酬を受け取る。運ばれている一行は、遺体が街に着くまで消息不明のまま残る。
- 強欲なリーダーの一行は、依頼が出ていなければ6割の確率で遺体を置き去りにする。そのとき装備と金だけを持ち去る。
- 遺体を担いだ一行が全滅すると、担いでいた遺体も再び迷宮に残される。

### 経験値とレベル

- 戦闘に勝つと、経験値は生き残った者で分け合う。
  - 強い魔物ほど、数が多いほど多くもらえる。
  - 地図のない階では7割になる。
  - 変異種なら、その倍率がかかる。
  - 人間は1.1倍もらえる。素質（凡庸・並・有望・天賦）、得意や不得意（早熟・大器晩成・覚えが悪い）でも増減する。
- レベルが上がるのは街に帰ったときだけである。迷宮の中では上がらない。
- 次のレベルまでに要る経験値は、レベルが上がるほど急に増える。目安は、レベル1→2が15、5→6が405、10→11が約2500、20→21が約26000、30→31が約15万。
- レベルが上がると最大体力が増える。攻撃力と呪文の力は、2レベルに1度ほど伸びる。
- 呼び名はレベル10で一人前、20でベテラン、30で英雄、40で伝説となる。
- 上級職への転職は「冒険者」の章の「上級職と転職」を参照。

### 帰還

- 地上に戻ると、稼ぎを生き残った者で山分けする。お触れによって、遺物の買い取り値が上がる時期や、探索税が引かれる時期がある。
- 各自は分け前の一部を酒場で使い、宿代と装備の手入れ代を払う（「店と街」の章の「常連」を参照）。銀の杯亭の冒険者は、分け前から借金を返す。
- 体力、呪文の力、毒が回復する。
- 帰還のたびに、転職、不得意の克服、二つ名、夢、引退の判定がある（「冒険者」の章を参照）。
- 帰還した一行の冒険談が、酒場の土産話として残る（「画面と語り」の章を参照）。

## 店と街

### 店主にできる操作

店主は冒険者を直接は動かせない。できるのは、店の金を使って支えることと、見ることである。

| 場所 | 操作 | 費用 |
|---|---|---|
| 上部 | 速度の切り替え、1日放置する | なし |
| 一行の札 | 押すと、その一行が遠見の水晶に映る。銀の杯亭の一行は、すれ違ってから少しのあいだしか映せない | なし |
| 水晶 | 探索中の自分の店の一行に、伝書鳩で撤退を命じる。命じられた一行はすぐ帰路につく | 50G |
| 名前 | 冒険者の手帳を開く | なし |
| 帳場 | 借金を返す（1000G・10000G・全額） | 返す額 |
| 帳場 | 店を広げる（席を増やす） | 段階で変わる |
| 帳場 | 支援の方針を決める（回復薬・地図代・蘇生代・新人への贈り物） | 使ったときに払う |
| 帳場 | 寺院で眠る常連の蘇生を頼む | 蘇生代 |
| 帳場 | 酒場にいる常連に、武具屋の品を贈る | 品の値段 |
| 帳場 | 消息不明の一行について、死体回収の依頼を出す | 報酬を前払いで預ける |
| 帳場 | 寺院に寄進する | 最深到達の深さで変わる |
| 番付 | 裏通りの酒場に出資する・買い取る | 出資は数万G、買収は15万〜60万Gほど |
| 帳場 | 店の設備を建てる | 30万〜80万G |
| 帳場 | 銀の杯亭の客を引き抜く | 借金＋支度金 |
| 武具屋 | グンター親方に特注の品を打たせる | 15万Gから |
| 武具屋 | 品書きの段（鉄の品など）を切り替えて見る | なし |

- 帳場の札には、寺院で眠る常連の数が出る。返済日まで3日を切ると「返済」の印も付く。
- 帳場のいちばん下に「最初から始める」がある。確かめたうえで、いまの記録を消し、借金をして店を開くところから始め直す。消した記録は戻らない。

### 借金と返済

- 黒猫亭は、セーレの両替商から借りた80000Gで開いた店である。最初の所持金は400G。
- 30日ごとに返済日が来る。返済日には、まず残りの2%が利息として借金に足される。そのうえで「4000G＋利息」を払う（残りがそれより少なければ残り全部）。
- 所持金で足りれば、自動で払われる。
- 足りないときは、あるだけ払う。不足分の25%が罰金として借金に上乗せされ、評判が3下がる（0より下にはならない）。取り立て人が店先に居座った、という知らせが出る。
- 帳場では、返済日を待たずにいつでも返せる。1000G、10000G（どちらも借金の残りより少ないときだけ出る）、全額の3つから選ぶ。所持金を超える額は返せない。
- 借金を返し終えると評判が10上がり、その日付が帳場に残る。

### 席と拡張

- 席の数が、店に籍を置ける常連の上限である。寺院で眠る者や行方不明の者も1席を使う。ロストした者と店を去った者は数えない。
- 席が空いていれば、ときどき新顔がやってくる。席が埋まっていると、新顔は来ない。救い出された身内も、空きがなければ客にならない（「身内探し」を参照）。
- 黒猫亭は12席から始まる。帳場で店を広げられる。

| 拡張 | 費用 |
|---|---|
| 12席 → 18席 | 5000G |
| 18席 → 24席 | 15000G |
| 24席 → 30席 | 40000G |
| 30席 → 36席 | 100000G |

- 36席より先は広げられない。銀の杯亭は32席である。
- 裏通りの酒場を買い取って支店にすると、1軒につき6席増える（「裏通りの酒場」を参照）。

### 常連

- 常連は、自分たちで一行を組んで迷宮に潜る（一行の作り方は「一行と迷宮」の章を参照）。
- 新顔の来やすさは「冒険者」の章の「新顔の来店」を参照。
- 酒場の札には、店のざわめき、帰ってきた冒険者の土産話、常連の席の埋まり具合、いま酒場にいる常連が並ぶ。

**常連が店に落とす金**

一行が街に帰ると、稼ぎは生きて帰った者で頭割りにする。そのうちの一部を、各自が店で使う。

- 使う割合は、ふだんは取り分の15〜30%である。酒好き・大食い・博打好きなら35〜55%になる。
- そこに次の割合が足される。
  - 店への恩×2%（20%まで）
  - 浪費家なら15%
  - 一行に人望のある者がいれば8%
- 常連はほかに、宿代と装備の修理代も払う。宿代は店に入り、修理代は店に入らない。
- 店で使った分と宿代を足したものが、店の売上になる。
- 帰還のたびに、店の評判が1＋（その探索で潜った最深階÷2、端数切り捨て）上がる。

**恩**

店主の世話を受けた常連は、店に恩を感じる。

| きっかけ | 恩 |
|---|---|
| 店主から品を贈られる | ＋2 |
| 店が蘇生代を払う | ＋1 |
| 銀の杯亭の引き抜きを断る | ＋1 |
| 差し入れの回復薬で助けられる | ＋0.3 |
| 店のもちで地図を使う | ＋0.2（一行の全員） |

- 恩が大きいほど、店でよく飲み、銀の杯亭に引き抜かれにくい。
- 恩が2以上になると、「店主に恩を返したい」という夢を持つことがある。この夢がかなうと、その者は3000G以上のまとまった金を店に置いていく。
- 恩が6に達すると、「店主には借りがある」が口癖になる。
- 恩が2以上の常連が店を去るときは、恩を返していく。理由は、夢、老い、身内の救出、弔いのどれでもよい。
  - 置いていく額は、所持金の6割と「その者の深さでの稼ぎ×（2＋恩）」（恩は10まで数える）の少ないほう。「店主に恩を返す」夢をもう叶えた者は、その半分。
  - 知らせは「店主には世話になった。この恩は忘れない」と、置いていった額を添える。
  - 手持ちが少なく300Gに届かないときは、金は置かず「いつか必ず、この恩は返す」と言い残して去る。
- 店を移ると、恩は0に戻る。

### 評判

| 増減 | 量 |
|---|---|
| 自分の店の一行が帰還する | ＋1＋（最深階÷2） |
| 自分の店の一行が、自分の店の最深記録を更新する | ＋3 |
| 借金を返し終える | ＋10 |
| 迷宮を踏破する（黒猫亭の一行が沈んだ王を討つ） | ＋50 |
| 返済日に払いきれない | −3 |

評判は次のことに効く。

- 新顔の来やすさ
- 店をたたんだ酒場の客が流れてくる確率
- 銀の杯亭との客の取り合い

黒猫亭の評判が初めて銀の杯亭を上回ると、「ロウエンでいちばんの酒場は黒猫亭だ」という知らせが出る。

### 支援（店の方針）

帳場で決めておくと、条件がそろうたびに自動で店の金が使われる。使った額は「これまでの支援」として帳簿に残る。

| 方針 | 中身 |
|---|---|
| 回復薬の差し入れ | なし／2本／5本から選ぶ。自分の店の一行が出発するとき、その本数を持たせる。1本の値段は一行の平均の深さで決まり、20G以上。店の金が足りなければ、その回は届かない |
| 地図を店のもちで買う | 常連の一行が、地図屋の地図がある階に着いたら、店が地図代を払う。店の金が足りなければ、一行が自分たちで買う |
| 蘇生代を肩代わりする | 常連が寺院に運ばれたら、店がすぐ蘇生代を払う。寺院で待っている常連の分も、店の金が足りた時点で払う |
| 新人に支度の品を贈る | レベル10未満の新顔が来たら、武具屋の品を2つまで贈る。値の張りすぎる品は贈らない |

- 差し入れの回復薬は戦闘で使われる。仲間の体力が3割を切り、使い手が呪文で癒やせないときに使う。1本で最大体力の4割を回復する。
- 贈り物（帳場から手で贈る場合も、新人への支度の品も）は、武具屋に並んでいる品から、その者が使えて、いまの装備よりはっきり良くなるものが選ばれる。値段に対して効き目のいちばん大きい品になる。外した古い装備は、本人が売って金にする。
- 死体回収の依頼を出すと、同じ階を歩く一行が遺体を見つけやすくなる。欲深いリーダーも、依頼の出ている遺体からは装備をはぎ取らず、連れ帰る。
  - 報酬はその階の深さで決まり、100G以上。出すときに店が預ける。
  - 遺体を連れ帰った一行に、帰還したとき支払われる。
  - 連れ帰る途中でその一行も全滅したら、預けた金は店に戻る。
  - 銀の杯亭の一行にも依頼を出せる。
  - 誰にも見つからず迷宮に呑まれたら、依頼は取り下げられ、預けた金は戻る。

### 寺院の費用と店の立て替え

- 蘇生代は、その冒険者の強さに見合った深さで決まる。灰からの蘇生は、死からの蘇生の3倍かかる。お触れで5割増しや半額になることがある。
- 蘇生は失敗することがある。

| 状態 | 成功 | 失敗すると |
|---|---|---|
| 死 | 84%から。強いほど上がり、最大97% | 灰になる |
| 灰 | 70%から。強いほど上がり、最大94% | ロストし、名が記念碑に刻まれる |

- 信心深い者は、どちらも成功しやすい。
- 寺院に寄進しているあいだは、黒猫亭の常連はどちらも8ポイント成功しやすくなる。上限も、死は99%、灰は97%に上がる（「大きな使い道」を参照）。

**一行が遺体を連れ帰ったとき（黒猫亭）**

1. 「蘇生代を肩代わりする」を選んでいて、店の金が足りれば、店が払う。
2. そうでなければ、本人の金で払う。
3. 本人の金で足りず、死んだのが連れ帰った一行の仲間なら、生き残った仲間が出し合う。
4. それでも足りなければ、寺院で待つ。帳場から店主が蘇生を頼むこともできる。
5. 2.4日（120刻）待っても誰も払わなければ、寺院が本人の借りとして蘇生する。このとき本人の所持金はマイナスになる。

### 大きな使い道

借金を返し、席を広げきったあとの店の金の使い道。どれも帳場か武具屋の札から使う。使った額のうち、寄進と特注は「これまでの支援」に入る。

**寺院への寄進**

- 寄進すると、30日のあいだ、黒猫亭の常連の蘇生が成功しやすくなる（「寺院の費用と店の立て替え」を参照）。
- 効き目のあるうちに重ねて寄進すると、そのぶん日が延びる。
- 額は、黒猫亭の最深到達の深さで決まる。B30Fまで届いていれば、およそ15万G。

**店の設備**

一度建てれば、ずっと効く。

| 設備 | 費用 | 効き目 |
|---|---|---|
| 修練場 | 300000G | 常連が戦いで得る経験が15%増える |
| 情報屋 | 500000G | 常連の一行が宝箱の罠を外す確率が10ポイント上がり、地図のない階で不意打ちを受ける確率が半分になる |
| 療養所 | 800000G | 帰還した常連の一行の休みが、14〜24刻から8〜14刻になる |

**銀の杯亭の客を引き抜く**

- 銀の杯亭の客のうち、酒場にいて、一行が迷宮に出ていない者に声をかけられる。レベルの高い順に5人まで出る。
- 黒猫亭の席が空いているときだけ声をかけられる。
- 費用は、その客の銀の杯亭への借金と、腕に見合った支度金（その者の強さに見合った深さの稼ぎ25回分）の合計。借金は店主が肩代わりし、0になる。
- 迎え入れた者は黒猫亭の客になり、店主に恩を感じる。銀の杯亭のロドリックが嫌味を言った、という噂が流れる。

**親方の特注**

- 武具屋に澱鉄の品（段7）が並ぶようになると、グンター親方に、常連ひとりのための品を打たせられる。
- 打たせられるのは、酒場にいるレベル20以上の常連で、いまの装備よりはっきり良くなる品がある者だけ。
- 品の出来は、店売りの段で数えて8から始まる。同じ者に頼むたびに1段ずつ上がり、12で止まる。
- 値段は150000Gから始まり、同じ者に頼むたびに1.35倍になる。
- 品には「グンター銘の○○（△△のための□作目）」と名が付く。外した古い装備は、本人が売って金にする。

### 武具屋（鉄床通りの武具屋）

- 両方の酒場の冒険者が使う店である。店主が直接買うことはできず、贈り物として使う。
- 冒険者は帰還後に、良い品があれば自分の金で買う（1回の帰還で2つまで）。手元に少し金を残して買う。金のかかる夢を持つ者は、多めに貯金を残す。外したお古は、酒場にいる仲間に譲るか、売る。
- 冒険者が迷宮から持ち帰った素材は、武具屋に買い取られる（1個につき「その素材の段×40G」）。決まった数が集まると、上の段の品が並びはじめる。最後の素材を持ち込んだ一行の名が、知らせに出る。

| 段 | 品 | 必要な素材 | 基本の値段 |
|---|---|---|---|
| 1 | 鉄の品 | 最初からある | 150G |
| 2 | 鋼の品 | 銀鉱石120 | 1500G |
| 3 | ミスリルの品 | ミスリル鉱300 | 3000G |
| 4 | 竜骨の品 | 竜骨250 | 4800G |
| 5 | 神銀の品 | 月長石40 | 7000G |
| 6 | アダマンの品 | 冥銀鉱60 | 11000G |
| 7 | 澱鉄の品 | 澱晶30 | 18000G |

- 両手武器は基本の値段の1.4倍、装飾品は1.2倍、盾と頭の防具は0.7倍である。
- 武具屋の札には、素材の集まり具合、段ごとの品書き（効き目と値段）、最近の買い物10件が出る。集まり具合は段2から段7までで、集めた数と、その段の品が並びはじめるのに必要な数を出す。横の棒はその割合で、必要な数に達すると満タンになり、数の代わりに「入荷済み」と出る。

### 地図屋（梟の地図屋）

- B1FからB10Fまでの地図は、最初から売られている。
- ほかの階は、ある一行がその階を最初に突破してから、数日後に地図が出る。深い階ほど遅い。
- 地図が出るとき、地図屋は最初に突破した一行から記録を買い取る。代金は地図の値段の半分で、その一行の生きている者に配られる。
- 地図の値段は、B1Fが40G、B2Fが80G、B3Fが150G。そこから先は深いほど高い（B11Fで約2350G、B20Fで約6670G、B30Fで14000G）。
- 一行は、地図のある階に着くと地図を買う。ただし、皆の所持金を合わせて値段の1.5倍に届かないと買えない。「地図を店のもちで買う」を選んでいれば、店が払う。
- 地図のある階では、罠を避けやすく、不意打ちも受けにくい。
- 地図屋の札には、各階の初到達と初突破の一行（上の階がまだ突破されていないのに罠で飛ばされて初到達したときは「（罠で飛ばされて）」と添える）、地図の状態（販売中・作成中・突破待ち・未踏）、名のある魔物、門番の黒竜の状況が出る。

### お触れ

- いま出ているお触れと残りの日数は、迷宮日報の札のいちばん上に出る。

| 出どころ | 中身 | 期間 | 出やすさ |
|---|---|---|---|
| ラウレンツ王国 | 報奨金。両方の酒場の最深より1つ深い階に最初に着いた一行に、一人あたりの報奨金を出す。額は、その深さでの1回の探索の分け前のおよそ10倍で、お金の夢が一度で叶うほどの大金になる（B16Fで約32500G、B20Fで約44900G、B30Fで約80900G）。払われた時点で終わる | 6〜10日 | 2 |
| ラウレンツ王国 | 探索税。帰還した一行の稼ぎの15%を納める | 4〜7日 | 2 |
| 灰の寺院 | 蘇生代を5割増し | 4〜7日 | 1.5 |
| 灰の寺院 | 聖日につき蘇生代を半額 | 2〜3日 | 1 |
| セーレ自由都市同盟 | 遺物と素材の買い取りを25%上乗せ。帰還した一行の稼ぎが1.25倍になる（税はそのあとにかかる） | 4〜6日 | 1.5 |
| 噂 | グラウ帝国から傭兵くずれが流れてくる。両方の酒場で新顔の来る確率が1.8倍になり、その半分はグラウ帝国出身の人間になる | 4〜6日 | 1 |

- 報奨金のお触れが出ているあいだは、届きそうな一行が深く攻めることがある。

### ライバルの銀の杯亭

主人はロドリックである。黒猫亭とは次の点が違う。

| | 黒猫亭 | 銀の杯亭 |
|---|---|---|
| 始まり | 評判0、借金80000G | 評判60、金は事実上尽きない |
| 最深到達 | B1Fから | B10Fから（古い記録） |
| 席 | 12席から、最大36席 | 32席 |
| 新顔の来る確率 | 評判で変わる | 1刻ごとに1.8%で一定 |
| 帰還ごとの評判 | ＋1＋最深階÷2 | ＋最深階÷3 |
| 水晶 | いつでも覗ける | すれ違ったときだけ映る |
| 装備 | 自前と店主からの贈り物 | 店が貸し付ける |
| 蘇生 | 本人・仲間・店が払う | 代金は客の借金になる |

- 銀の杯亭では、平均レベルのいちばん高い一行が「看板」になる。看板が全滅したその刻に、別の一行へ代わる。代わりがいなければ、看板は空く。
- 銀の杯亭の一行の全滅は、噂でしか伝わらない。

**貸し付け**

- 銀の杯亭の新顔は、自分の強さより上等な装備を店から借りる。その代わり、深さに応じた借金を負う。
- 帰還のたびに、稼ぎの取り分の40%が取り立てられる。
- 借金のある者を含む一行は、引き返すのが遅く、深く攻めることが多い。
- 寺院で眠る客の蘇生も店が頼み、その代金は客の借金に足される。

**客の取り合い**

- 引き抜き：21日目以降、銀の杯亭に空き席があれば、10日ごとに60%の確率で起きる。
  - 狙われるのは、酒場にいる黒猫亭のレベル8以上の常連のうち、いちばんレベルの高い者（家族を探す夢を持つ者は除く）。
  - 応じる確率は35%が基準である。恩が大きいほど、また黒猫亭の評判が銀の杯亭に比べて高いほど下がる（3%〜50%）。
  - 断った者は恩が1増える。
- 逆に流れてくる客：12日ごとに、黒猫亭に空き席があれば起きることがある。
  - 確率は15%＋25%×（評判の比。1.4までしか効かない）。
  - 銀の杯亭の、借金を抱えて街にいる客（看板の一行は除く）が、取り立てに嫌気がさして黒猫亭に移る。借金は踏み倒される。
- 40日ごとに、銀の杯亭についての噂が流れることがある。

### 裏通りの酒場

- 裏通りには小さな酒場がいくつかある（最初は5軒、多くて6軒）。どの店にも、主人、店の特色、景気がある。特色は店ごとに違う。
- 景気は出来事で上下し、繁盛・ふつう・客足が落ちている・傾いているの4段階で表す。
- 4〜8日後から、6〜12日ごとに次のどれかが起きる。

| 確率 | 出来事 | 景気 |
|---|---|---|
| 傾いた店があれば50% | 傾いた店をたたむ（開いて10日以内の店はたたまない） | ― |
| 15% | 新しい酒場が開く。6軒そろっているときは、ほかの出来事を選び直す | ふつうから始まる |
| 25% | その店の一行が全滅したという噂 | 下がる |
| 20% | 大きな稼ぎを持ち帰ったという噂 | 上がる |
| 12% | 常連が銀の杯亭に引き抜かれたという噂 | 下がる |
| 12% | 銀の杯亭の客と殴り合いになったという噂 | 下がる |
| 残り | 客でにぎわっているという噂 | 上がる |

- 店をたたむ理由は、その店に最近あった悪い出来事で決まる（一行を迷宮で失った、常連を銀の杯亭に持っていかれた、揉め事続き）。悪い出来事がなければ「借金が返せず」になる。
- たたんだ店の名前は、もう使わない。
- 店がたたまれたとき、黒猫亭に空き席があれば、その店の元常連（レベル3〜10）が流れてくることがある。確率は30%＋評判×0.3%（最大70%）。
- 傾いた店をたたむのは、黒猫亭が後ろ盾になっていない店だけである。出来事が起きるのは、黒猫亭の支店になっていない店だけである。
- 黒猫亭が後ろ盾の店に「常連が銀の杯亭に引き抜かれた」が当たったときは、銀の杯亭が後ろ盾を知って引き下がったという噂になり、景気は下がらない。

#### 出資と買収

番付の札の「裏通りの酒場」から、支店でない店ごとに出資と買収ができる。

- **出資**
  - 景気が「繁盛」でない店に出資できる。景気が2段階上がり（上限は繁盛）、黒猫亭が後ろ盾になる。黒猫亭の評判が2上がる。
  - 額は黒猫亭の最深到達の深さで決まり、同じ店に出資するたびに1.5倍になる。B30Fまで届いていれば、1回目でおよそ2万7千G。
- **買収**
  - 値段は30万Gをもとに、景気で変わる。傾いていれば半額、客足が落ちていれば0.8倍、ふつうなら1倍、それより上は1.5倍、繁盛なら2倍。支店を持つたびに、次の値段が1.3倍になる。
  - 買い取った店は黒猫亭の支店になり、主人がそのまま店を任される。たたまれることはなく、出来事も起きない。
  - 支店1軒につき、黒猫亭の常連の席が6増える（店の拡張の上限36席とは別に足される）。
  - 買い取ったとき、その店の常連が1〜3人、黒猫亭に籍を移してくる（席が空いているぶんだけ）。レベルの決まり方は、評判を聞いて来る新顔と同じ。
  - 銀の杯亭のロドリックが嫌味を言った、という噂が流れる。
- 一覧では、支店には「黒猫亭の支店」、後ろ盾の店には景気のあとに「黒猫亭が後ろ盾」と出る。

- 番付の札に「裏通りの酒場」の一覧が出る。店ごとに、名前、景気、主人、特色、最近の出来事（日付つき）が並ぶ。その下に、たたんだ店の名前と、たたんだ日と理由が出る。

### 番付

番付の札では、黒猫亭と銀の杯亭を8つの項目で比べる。勝っている側の数字が太字になる。

- 最深到達
- 解禁後に初到達した階の数
- 最初に突破した階の数
- 名のある魔物の討伐数
- かなえた夢の数
- 常連の数
- 評判
- ロストした者の数（少ないほうが勝ち）

黒猫亭が勝っている項目の数で、一言が変わる。

| 勝っている項目 | 一言 |
|---|---|
| 6つ以上 | 「もう、黒猫亭を新参と呼ぶ者はいない」 |
| 4〜5つ | 「肩を並べはじめている」 |
| 3つ以下 | 「まだ追いかける側だ」 |

番付の札には、裏通りの酒場の一覧、迷宮の記録の断片、踏破した一行も載る。

### 勝ち負けと終わり

- はっきりした勝ち負けや、遊びの終わりはない。借金を払えなくても、店はつぶれない。罰金と評判の低下があるだけである。
- B30Fの沈んだ王が討たれると、迷宮は踏破されたことになる。
  - 踏破した一行の一人ひとりに、王国から報奨金が出る。
  - 黒猫亭の一行が討った場合は、店に祝い金50000Gが届き、評判が50上がる。
- 踏破すると、その夜のひと幕が一度だけ画面に出る。留守のあいだのまとめが出ているときは、それを閉じたあとに出る。
  - 黒猫亭の一行が討った場合は、店が朝まで祝う。銀の杯亭のロドリックからも、渋々の祝いの酒が届く。
  - 銀の杯亭の一行が討った場合は、ロドリックが黒猫亭まで嫌味を言いに来る。店に借金が残っていれば、その返済のことも当てこする。閉じるボタンは「見返してやる」になる。
- 踏破のあとも、迷宮も店も、そのまま続く。

**左の列**

  - 平均レベル、人数、リーダーの名前、今の様子。
  - 黒猫亭の一行だけ、一人ずつの体力を色の帯で示す。

| 表示 | いつ出るか |
|---|---|
| B○F 探索中／腕を磨いている／深く攻めている | 迷宮を歩いている。言葉はその回の方針で変わる |

**留守のあいだに**：店を閉じていたあとに開いたときと、「1日放置する」を押したときに出る（「時間と保存」の章を参照）。

- 帳場：寺院で眠る常連がいると「寺院○」が付く。借金の返済日まで3日を切ると「返済」が付く。

**酒場タブ**

- 酒場のざわめき：新しい順に8件。
- 土産話：新しい順に12件。見出しは「話半分に聞くこと」。それぞれに次のものが付く。

  - 性格と日付。

  - 性別と年齢、出身、レベル、種族と職業。

**名簿タブ**

- 黒猫亭の常連を4つの組に分けて並べる：寺院で眠る者、探索中、酒場、行方不明。ロストした者と店を去った者は出ない。
- 一人ずつ次のものが出る。
  - 状態の札。
  - 二つ名、名前、所属する一行。
  - 異例・レア・上級の印。

### 遠見の水晶（迷宮内のログ）

**どの一行が映るか**

- 水晶は1つで、一度に1つの一行だけを映す。
- 一行の札を押すと、その一行が映る。
- 映せない一行もある。
  - 銀の杯亭の一行：こちらの一行とすれ違ってから30刻のあいだだけ映せる。それ以外のときに押すと「銀の杯亭の一行は、すれ違ったときしか見えない」と出る。
  - 黒猫亭の一行で全滅がまだ知れていないもの：押すと「水晶は闇しか映さない」と出る。
- 映していた一行について次のことが起きると、迷宮にいる黒猫亭の一行に勝手に切り替わる。
  - 一行がいなくなった。
  - 街に戻って次の出発が近い。
  - 銀の杯亭の一行が見えなくなった。
- 映すものが何もないときは「水晶は くもっている」と出る。

**水晶に出るもの**

- 上の欄：一行の名前（銀の杯亭なら「（銀の杯亭）」が付く）、今の様子、今いる区画、地図あり／地図なし。
- 仲間の欄：最大6人。リーダーには★が付く。それぞれの体力が出て、毒なら「毒」、倒れていれば「しぼう」と出る。体力が少ない者と死んだ者は色が変わる。
- 下の欄：
  - 黒猫亭の一行が探索中なら「伝書鳩で撤退を命じる（50G）」のボタンが出る。押すと、ログに「でんしょばとが まいおりた。「すぐ もどれ」」と出て、リーダーが「……店主の めいれいだ。もどるぞ」と言い、一行は帰り道につく。
  - それ以外のときは「帰路についている」などの様子が出る。
  - 右端に今回の稼ぎが出る。

**ログの見え方**

- ログは直近の60行を出す。新しい行は一行ずつ順に浮かび上がる。
- 一行が全滅すると、最後に「水晶は もう なにも うつさない」と出る。
- 文章はひらがなを空白で区切った古いゲームの書き方である（例「くらい つうろを すすむ」）。
- 行は種類ごとに色が違う。

| 種類 | 見え方 | 主な中身 |
|---|---|---|
| 進行 | 白・中央寄せ | 出発、階段、魔物の出現、区画の境目、宝箱、すれ違い |
| 台詞 | 淡い黄色 | 冒険者の言葉（「名前「……」」の形） |
| 危険 | 赤 | 罠、毒、ブレス、不意打ち、死、全滅、誰も知らない階に入った |
| 収穫 | 緑 | 勝利と経験値、拾った物、装備、くびをはねた、回復薬の差し入れ |
| 移動 | 淡い色 | 通路の様子、攻撃をかわした、買えなかった地図 |
| レベル | 薄紫 | レベルが上がった |

**深い階の雑音**

- B6Fから下では、進行の行を除いて、文字の一部が「…」「ザ」「ｻﾞ」「・」に化ける。
- 化ける割合は、1階深くなるごとに3%ずつ増え、最大で20%である。

**魔物の名前**

- 正体が分からないあいだは見た目で書かれる（例「あやしい ひとかげ ×3」）。正体の分かり方は「一行と迷宮」の章の「戦闘」を参照。

**台詞の種類**

- リーダーが性格に応じて言うもの：
  - 進む、下りる、引き返すとき。
  - 出発のときの方針。理由があれば、たとえば「ぎんのさかずきていに まけて たまるか」と言う。
- 探索中、ときどき誰かの癖が出る（例：酒好きが水筒の酒をこっそり飲む）。
- 怖いものに出会ったとき：怖いものの魔物、区画、地図のない階で、それを怖がる者がおびえる。
- 戦いの掛け声：名のある魔物が相手なら6割、ふつうの戦いなら8%の確率で出る。口癖が混じることがある。
- 倒れるとき：口癖を持つ者は、35%の確率で最期の言葉を言う。
- 夢の階：夢に見た階に着いた者は「……これが B○Fの けしき……」と言う。
- 水晶の中の台詞には、下で述べる口調の変化はかからない。

### 知らせ（迷宮日報）

**集め方と見せ方**

- 知らせは黒猫亭の出来事も銀の杯亭の出来事も届く。
- 記録として残るのは最新の300件。迷宮日報には最新の60件を新しい順に出す。
- それぞれに「○日目」が付く。
- 知らせは種類ごとに色が違う。

| 種類 | 見え方 | 主な中身 |
|---|---|---|
| お触れ | 太字 | 王国・寺院・同盟のお触れ、【噂】として流れるお触れ、地図屋の地図の売り出し、踏破の褒美 |
| 記録 | 琥珀色 | 誰も入ったことのない階に着いた、名のある魔物を倒した、黒竜を倒した、伝説の品を見つけた、二つ名で呼ばれはじめた、夢がかなった、店を去った、転職した、レベルが10の倍数に届いた、珍しい新顔が来た、銀の杯亭から移ってきた、武具屋に新しい品が入った、店を広げた、借金を返し終えた、ロウエンいちの酒場になった |
| ふつう | 地の色 | 一行の結成と加入、新顔、解散、毎月の返済、遺体の発見と回収、贈り物、苦手を克服した、裏通りの酒場が開いた・たたんだ |
| 噂 | 銀の杯亭の色 | 銀の杯亭の一行の出来事（「噂：」で始まることが多い）、銀の杯亭の主人の言葉、看板の交代、引き抜きを断られた、裏通りの小さな酒場の噂、黒竜がよみがえった |
| 凶報 | 赤 | 一行が予定を過ぎても戻らない、水晶が一行の最期を映した、蘇生に失敗して灰になった、返済が足りなかった |
| 喪失 | 灰色 | ロストした、一行が見つからず記念碑に刻まれた、銀の杯亭に引き抜かれた |
| 収穫 | 緑 | 400G以上を持ち帰った、寺院で生き返った、倒れた者の装備を拾った、踏破の祝い金 |
| 記録の断片 | 薄紫 | 迷宮で見つかった古い記録の文面 |

**黒猫亭の一行が全滅したとき**

- その一行を水晶で見ていたら、すぐに「水晶が○○の最期を映した。B○F、△△に倒れる。」と知らせる。深く攻めていた理由があれば、それも書き添える。
- 見ていなかったら、15刻たってから「予定を過ぎても戻らない」と知らせる。理由と最後に向かった階も書く。

**銀の杯亭の一行が全滅したとき**

- 25刻たってから、「戻らないらしい」という噂が流れる。

### 酒場のざわめき

**会話が起きる条件**

- 黒猫亭の酒場に2人以上いるとき、1刻ごとに5%の確率で会話が起きる。
- 話し手Aは酒場にいる者から選ぶ。相手Bも酒場にいる者から選ぶ。
- 半分の確率で、Bは絆の深い相手ほど選ばれやすくなる。絆の深さは、一緒に潜った回数と二人で経験した出来事の数で決まる。

**話題の選び方**

- そのときに使える話題を集め、重みに応じて1つ選ぶ。
- 会話はふつう2行で、話題によっては3行になる。
- 直近の8件と最初の一言が同じなら、その会話は捨てる。最初の一言の終わり8文字が同じときも捨てる。
- 酒場タブに出るのは新しい順に8件で、記録として残るのは40件までである。

| 話題 | 使える条件 | 重み |

### 土産話

**誰が話すか**

- 一行が街に帰るたびに、生きて帰った者の1人が土産話を1つ話す。銀の杯亭の一行も話す。
- 生きて帰った者が2人以上いれば、35%の確率でもう1つ話が出る。2つ目は、直前の土産話と違う者が話す。

**話を盛る者**

- 強欲か無謀な者は話を盛る。数や金額を2〜4倍にして言い、「城の門ほど」「ほとんど俺ひとりで」のように大きく言う。
- そのため見出しは「話半分に聞くこと」である。

**話の型**

話す者と今回の探索に合う型を集め、重みに応じて1つ選ぶ。よく出る型には、言い回しが3〜4通りある。

| 分類 | 型と条件（重み） |
|---|---|
| 戦い | 倒した数（2）、群れに囲まれた（1）、もう慣れた（1）：魔物を倒したとき／大物の大きさや手応え（2.5、1.5）：やや深い魔物と戦ったとき／くびをはねた（3）：自分のとき、仲間のとき／ネムリでまとめて眠らせた（2）：3体以上のとき／イヤシを唱え続けた（1.2）：4回以上のとき |
| 危険 | 死にかけた（3）：自分または仲間が瀕死になった／罠（テレポーター3、爆弾2.5、ほか2）／毒（1.5）／逃げ出した（慎重か臆病なら2.5、ほかは1） |
| 喪失 | 仲間が倒れた（5） |
| 収穫 | 拾った品（2.5）／600G以上の稼ぎ（2）／骨折り損（1.5）：稼ぎが少なく、品もない |
| 探索 | 黒猫亭の差し入れの回復薬（2）／ダッシュツで助かった（5）／ヨミガエリ（5）／手強い変わり種の魔物（2.5）／名のある魔物を見た（4）／一番乗り（5）／深い階の空気（1.5、1）：B4Fより下まで潜ったとき／浅いところだけ（0.8）／ほかの一行とすれ違った（1.5）：銀の杯亭が相手なら愛想が悪いと話す／倒れた一行を見つけた（4）／肉親を探しに行った（6） |
| 成長 | レベルが上がった（2） |
| 人柄 | 癖の話（1.5）／夢の話（1）：お金の夢なら残りの額、深い階・黒竜・肉親探しの夢ならその進み具合／出身地の話（1.3）／性格の話（臆病・無謀・慎重・強欲は1、普通は0.8） |
| 好物 | 帰ったら好物を食べる（1） |
| 怖いもの | 怖いものの魔物を倒した（3）／苦手な区画まで潜った（3）／どちらでもなく「今回は出くわさずに済んだ」（0.6） |
| 口癖 | 「『口癖』って、今回も何度言ったか」など（0.8） |
| 職業 | 獣使いは相棒の話（2）。吟遊詩人・錬金術師・盗賊系・回復役・後衛の魔術師・前衛は職業らしい話（1.5） |
| 絆 | 一緒に潜った仲間のうち、最も絆が深い1人の話。8回以上一緒なら「背中を任せられる」（1.5）、1回以下なら「初めて組んだ」（1） |

**同じ型が続かない仕組み**

- 直近15件の土産話とまったく同じ文は選ばない。ただし、候補が全部それに当たるときは選ぶ。
- 直近12件に同じ型が出ていれば、その型の重みを1回ごとに5分の1にする。2回出ていれば25分の1になる。
- このため、数字や名前だけが違う同じ型の話は続きにくい。

**仕上げ**

- 選んだ文に、話す者の口調と一人称をかける。
- 15%の確率で口癖で締める。

### 口調

**口調の決まり方**

冒険者は次の8つの口調のどれか1つを持つ。口調は生まれと人柄で決まりやすさが変わる。

| 口調 | もとの重み | 選ばれやすくなる者 |
|---|---|---|
| 普通 | 4 | ― |
| ぶっきらぼう | 2 | 無謀（2倍） |
| 丁寧 | 1.5 | 聖オルド教国の出身・僧侶・司教（2.5倍）、臆病（2倍）、エルフ（2倍） |
| 陽気 | 1.5 | 無謀（2倍）、人間でいえば18歳未満（2倍） |
| 無口 | 0.5 | 癖が「無口」（4倍） |
| 古風 | 0.5 | 人間でいえば50歳以上・侍・剣聖・東方の島国アズマの出身（6倍） |
| 商人言葉 | 0.4 | セーレ自由都市同盟の出身（8倍） |
| 田舎なまり | 0.4 | カルセ王国・麦穂の丘・ハザン草原の出身（6倍） |

**口調がかかる場所**

- 酒場のざわめきと土産話にかかる。
- 迷宮の中の台詞にはかからない。

**語尾の変え方**

- 変えるのは文末（「。」「！」「？」の直前か文の終わり）の「だ」「だな」「だよ」「だぞ」「だぜ」「だろう」である。
- 過去形の動詞の「〜んだ」（「死んだ」「すくんだ」など）は「だ」と見なさず、そのまま残す。

| 口調 | 変え方 |
|---|---|
| 丁寧 | だろう→でしょう、だ→です、だな→ですね、だよ・だぞ・だぜ→ですよ。文末の「ぞ」「ぜ」「さ」は落とす（「っ」の後は残す） |
| 古風 | だろう→じゃろう、だ→じゃ、だな→じゃな、だよ・だぞ・だぜ→じゃぞ |
| 商人言葉 | だろう→やろ、だ→や、だな→やな、だよ・だぞ・だぜ→やで、「じゃない」→「やない」 |
| 田舎なまり | だろう→だべさ、だ→だべ、だな→だなや、だよ・だぞ・だぜ→だべよ |
| 陽気 | 文の最後の「。」を「！」にする。30%の確率で頭に「はは、」を付ける。ただし文が「は」「あ」「…」で始まるときは付けない |
| 無口 | 頭の「……」をいったん外す。17文字以上なら最初の一文だけ残し、その「。」も落とす。最後に頭へ「……」を付ける |
| ぶっきらぼう | 文末の「よ」「ね」を落とす |
| 普通 | 変えない |

**陽気がつらい話で笑わない仕組み**

- 陽気な者でも、文につらい話の言葉が入っていれば何も変えない。「！」にもせず、「はは、」も付けない。
- つらい話の言葉は次のものである：やられ・死・寺院・担いで・亡く・失っ・ロスト・灰に・墓・弔・記念碑・いいやつだった・放っておいて・そっとして・席が、ひとつ。

**一人称**

文の中の「俺」「僕」（と「あたしたち」の「あたし」）を、話す者の一人称に置き換える。上から順に当てはめる。

| 話す者 | 一人称 |
|---|---|
| エルフ | 私 |
| 人間でいえば40歳以上のドワーフ | わし |
| 女で、慎重か臆病か40歳以上 | 私 |
| ほかの女 | あたし |
| 55歳以上の男 | わし |
| 臆病な男 | 僕 |
| ほかの男 | 俺 |

口調によって一人称が変わる。

- 丁寧：「私」になる。ただし「わし」の者はそのまま。
- 古風な男：侍・剣聖・アズマの出身なら「拙者」、それ以外は「わし」になる。

**口癖で締める**

- 15%の確率で、文の後に口癖を付ける。酒場のざわめきでは2行目から付く。
- 次のときは付けない。
  - 文にもう口癖が入っている。
  - 文が「）」で終わる（例：無口な者の「……（黙って杯を掲げた）」）。
- 文が「！」か「？」で終わればそのまま後ろに付ける。それ以外は「。」で区切ってから付ける。

**口調や口癖が変わるとき**

| きっかけ | 確率 | 変わること |
|---|---|---|
| 5回以上一緒に潜った友がロストした | 30% | 無口になる（性格が変わらなかったとき） |
| 同じく、友を失ったとき | 30% | その友の口癖を真似る（性格も口調も変わらなかったとき） |
| 灰から生き返った | 25% | 無口になり、口癖が「……生きてるって、いいな」になる |
| 店主への恩が6に達した | ― | 口癖が「店主には借りがある」になる |

### 冒険者の手帳（年代記）

手帳の上半分には、その冒険者の今が出る。

- 二つ名、名前、状態、所属する一行。
- 所属する店、出身、性別と年齢（人間以外は実年齢も）、レベルと格（駆け出し〜伝説）、種族と職業、性格、癖、素質。
- 生い立ち。
- 口調、口癖、好物、怖いもの。
- 得意と不得意。天に愛された者や、星回りの悪い者にはそう書く。
- 変わったこと（日付つき）。
- 異例の冒険者の説明、上級職やレア職業の説明、相棒の獣。
- 種族の得意と苦手。
- 今の夢と進み具合、かなえた夢（日付と添え書きつき）。
- 討伐数・最深到達・蘇生の回数・罠解除の数・所持金・体力。
- 装備（伝説の品には言い伝えも出る）、攻撃・守り・MP、所属。

下半分の「手帳」が年代記である。

- 出来事を新しい順に「○日目」とともに並べる。
- 書き留める主な出来事は次のとおり。
  - 店に来たとき：出身、生い立ち、年齢、種族と職業、レベル、そのときの夢。
  - 愛用の装備、銀の杯亭からの借り入れ。
  - 一行の結成・加入・脱退・解散・リーダーを継いだこと。
  - 初めて入った階（B3F以降）、レベルが上がったこと、拾った品や譲られた品、買った品。
  - 倒れたこと、寺院で生き返ったこと、灰になったこと。
  - 名のある魔物、黒竜、沈んだ王を倒したこと。
  - 二つ名で呼ばれはじめたこと、転職。
  - 新しい夢、夢がかなったこと、変わったこと、店主から受けた支援。
  - 店を去ったこと、ロストしたこと。
- 書き留めるのは90件まで。あふれたら、最初の1件（店に来たときの記録）を残して、その次に古いものから消していく。

### 記念碑

黒猫亭と銀の杯亭の両方の者を載せる。名前を押すと手帳が開く。

**店を去った者**

- 人数と、新しい順の一覧。
- 一人ずつ、名前（二つ名つき）、性別と年齢、レベル、種族と職業が出る。
- 添え書き：「○○亭の客。○日目、（去る理由）ため旅立った。」

**ロストした者**

- 人数と、新しい順の一覧。
- 一人ずつ、名前、レベル、種族と職業が出る。
- 添え書き：「○○亭の客。B○Fにて（倒した相手）に倒れ、蘇ることなく○日目に眠る。討伐○。」
- 全滅した一行が20日のあいだ見つからなかったときは、「ついに見つからなかった。……の名が記念碑に刻まれる」と知らせる。

### 夢がかなったときの知らせと、店を去る理由

**夢の文面と知らせを合わせる**

- 夢がかなったときの知らせと店を去る理由は、選ばれた夢の書き方と言葉に合わせて文面を変える。
- 去るかどうか（必ず、または何%か）は「冒険者」の章の夢の表に書く。

**夢がかなったとき**

- 知らせは「記録」の色で出る。銀の杯亭の者なら頭に「銀の杯亭の」が付く。
- 手帳には「夢がかなう――（夢の文面）」と書く。
- 去る理由がある夢では、そのまま店を去る。持っていた装備は、同じ一行の役に立つ者に託す。手帳にも「（理由）ため、○○亭を去る」と書く。
- 去るときの知らせは「○○亭の（名前）が、（理由）ため店を去った。」である。

**夢の文面に合わせて変わる例**

| 夢 | 文面に合わせて変わるところ |
|---|---|
| 故郷の借金 | 「○○が残した借金」なら「○○の残した借金を返し、家を取り戻した」と知らせる。「高利貸しに取られた（実家の畑など）」なら「（それ）をついに取り戻した」と知らせる |
| 店を構える | 夢の場所と店の種類（例：故郷の港町に茶屋）がそのまま知らせと去る理由に入る |
| 故郷に建てる | 寺院・孤児院・学び舎・施療院・石の橋・井戸と水車のうち、夢に書いたものが建つ |
| 名を上げる | 「吟遊詩人に歌われる」「子どもが真似をする」「王都の芝居に出る」「ロウエンの誰もが名を知る」の文面ごとに、知らせが対応する |
| 騎士になる | 仕える相手（若い王女、辺境の伯爵）が夢に入っていれば、その名が知らせと去る理由に入る |
| 仇討ち | 「兄の命を奪った」などの因縁が知らせに入る |

**店を去る理由**

| 夢 | 去る理由 |
|---|---|
| 海を渡って故郷へ帰る | 海を渡って故郷へ帰る。文面に待つ人が入っていれば「海を渡って故郷の（母・妻子・師匠・一族）のもとへ帰る」 |
| 財産を築く | 財を成し、悠々自適の暮らしに入る。文面に場所が入っていれば「（場所）に屋敷を構える」 |
| 店を構える | （場所）に（店）を構える |
| 故郷に建てる | 故郷に建てた（建てたもの）を守る |
| 騎士になる | 王国の騎士に取り立てられる、または「（相手）に仕える騎士となる」 |
| 余生の蓄え | 剣を置いて隠居する。文面に場所が入っていれば「剣を置いて（場所）で隠居する」 |
| 大陸を巡る | 大陸をめぐる旅に出る |
| 海の向こうを見る | 海を渡って（行き先）へ向かう |
| 所帯を持つ | 所帯を持つ |
| もう一度深く潜る | 思い残すことなく引退する |
| 自分の船 | 自分の船で海に出る |
| エルフの英雄譚 | 人の世の歌を携えて森へ帰る |
| 坑道を買い戻す | 買い戻した坑道へ帰る |
| 丸い窓の家 | 丘に帰って、丸い窓の家で暮らす |
| 名馬を買い戻す | 名馬に乗って草原へ帰る |
| 主君への供え物 | 主君の墓前へ帰る |
| 澱晶を持ち帰る | 澱晶を携えてザハルへ帰る |
| 聖都への巡礼 | 聖都へ巡礼に出る |
| リンデの公爵 | リンデ公国に召し抱えられる |
| 仇討ち | 仇を討ち、剣を置く |
| 故郷の借金 | 故郷へ帰る |
| 破門を解く | 教国へ戻り、もう一度神に仕える |
| 仲間の形見を届ける | 形見を届けたまま、故郷に留まる |

夢のほかに店を去るとき（老い、身内の救出、弔い）は「冒険者」の章の「引退」を参照。去る理由の文面は次のとおりである。

- 老い：「（年齢）。老いを感じ、冒険から身を引く」
- 身内の救出：「見つけ出した（続柄）の（名前）と故郷へ帰る」
- 弔い：「弔いの旅に出る」
